Eliott：Quickly Query Marketing Data with Natural Language

askeliott.com/

Eliott is an online tool designed to help users rapidly gain insights into marketing data through natural language processing.

Eliott is an online tool designed to help users quickly analyze and query marketing data using natural language. It utilizes natural language processing technology, enabling users to ask questions in everyday language and easily obtain marketing information. Eliott can connect to various marketing tools, with secure and efficient data processing, making it suitable for individuals, teams, and enterprises to make data-driven decisions rapidly. There is no complex configuration required, and users can experience a free trial after registration, which is straightforward, thus saving time. Eliott makes data analysis intuitive, helping users focus on core business.

Feature List

  • Natural Language Query: Users can ask questions in common language, such as “What was last week’s ad click rate?”, Eliott will automatically interpret and provide an answer.
  • Multi-Tool Integration: Supports connecting various marketing tools such as Google Analytics, HubSpot, Mailchimp, allowing for unified data management.
  • Data Dashboard: Provides an intuitive data visualization interface to display key metrics and trends.
  • Favorites Function: Users can save frequently used queries for convenient access to historical data.
  • Strategic Recommendations: Offers optimization suggestions based on data analysis, such as adjusting advertising strategies.
  • Secure Data Processing: Implements encryption measures to protect user data privacy, complying with GDPR and other relevant regulations.
  • Multi-Tier Pricing: Offers free trials and various paid plans to meet the needs of users of different scales.

User Guide

Installation and Registration

Eliott is a cloud-based SaaS platform, requiring no software downloads. Users simply need to visit the Eliott Registration Page to register an account for free trial without a credit card. The registration process is as follows:

  1. Visit the Registration Page.
  2. Enter the email, name, and password, then click “Register”.
  3. After verifying the email, log in to the Eliott Login Page.
  4. Enter the dashboard and connect various marketing tools as prompted.

Connecting Marketing Tools

Eliott allows for quick integration with various marketing tools, including Google Analytics, HubSpot, Mailchimp, the connection steps are as follows:

  1. After logging in, go to the “Integrations” page.
  2. Select the tool to connect (e.g., Google Analytics).
  3. Authorize Eliott to access the tool’s data (tool login credentials are required).
  4. Once connected successfully, Eliott will automatically synchronize data, which takes a few minutes.
  5. After data synchronization is complete, all aggregated data from the tools can be viewed in the dashboard.

Querying Data

The core function of Eliott is natural language querying. Users do not need to master complex query syntax; just enter questions into the query box, for example:

  • Enter “What was the website traffic last month?” Eliott will return specific values and trend graphs.
  • Enter “Which ad campaign has the highest conversion rate?” Eliott will list conversion rate rankings. The system supports multiple languages, and Chinese users can ask questions in Simplified Chinese, and Eliott will intelligently interpret the questions and return relevant data.

Using the Dashboard

The dashboard is Eliott’s data visualization center where users can:

  • View key metrics such as website traffic, ad click rates, and email open rates.
  • Customize the dashboard by adding frequently used data views.
  • Export data reports for team sharing or archiving. The dashboard supports real-time updates to ensure data accuracy.

Saving Favorites

Users can save frequently used queries as “Favorites.” The operation steps are:

  1. Enter a question in the query box and get the answer.
  2. Click the “Favorite” button next to the answer.
  3. Name the query, such as “Weekly Traffic Report.”
  4. Once favored, it can be quickly accessed in the dashboard, designed specifically for repetitive analysis scenarios.

Getting Strategic Recommendations

Eliott’s Pro and Premium packages offer strategic recommendation features. The system will provide optimization suggestions based on data analysis results, such as:

  • If the ad conversion rate is low, Eliott may suggest adjusting the audience or increasing the budget.
  • If the email open rate declines, Eliott will recommend optimizing the email subject line or adjusting the sending time. Users can check suggestions in the “Recommendations” area of the dashboard and apply them with one click.

Pricing and Package Options

Eliott offers three packages to meet different needs:

  • Basic ($22/month): Suitable for individuals or small teams, providing 50 queries per month, including dashboard and favorites features.
  • Pro ($104/month): Suitable for medium-sized teams, providing 150-500 queries per month while adding strategic recommendation features.
  • Premium ($468/month): Suitable for large enterprises, with unlimited queries and all functionalities. Users can choose to pay monthly or annually (annual payment enjoys a 20% discount). All packages support a free trial.

Data Security

Eliott employs encryption technology and secure storage measures to protect user data privacy. The platform complies with GDPR and CCPA regulations, ensuring transparent and compliant data processing. Users can view detailed policies at any time on the “Privacy Policy” page.

Operation Tips

  • Quick Start: New users are advised to start with simple queries, such as “What is today’s website visit volume?” Once familiar, they can attempt more complex questions, such as “Compare the conversion rates across channels last quarter.”
  • Optimize Queries: When asking questions, emphasize specificity to avoid vague expressions; for example, “This month’s email marketing conversion rate” is easier to get an accurate answer than “How is email performing.”
  • Regularly Check Connections: Ensure the connection status of marketing tools is normal to avoid data synchronization interruptions.
  • View Demo Videos: Eliott’s official website provides demo videos (video link) showcasing query and dashboard operations.

Application Scenarios

  1. Marketing Campaign Optimization: Marketing teams can quickly analyze advertising effectiveness through Eliott. For example, by querying “Which advertising platform has the highest ROI,” budget allocation can be adjusted based on recommendations.
  2. Data-Driven Decision Making: Business managers can utilize Eliott to aggregate multi-channel data, quickly understand business performance, and formulate strategic plans.
  3. Individual Freelancers: Freelancers can use the Basic package to monitor website traffic and social media effectiveness to optimize personal brand promotion.
  4. Team Collaboration: Teams can leverage the dashboard to share data views and unify analysis results, thereby improving collaboration efficiency.
