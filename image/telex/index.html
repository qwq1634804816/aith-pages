Telex：Official WordPress Tool for One-Click Generation of Modern WordPress Themes

telex.automattic.ai/

Telex is an experimental AI tool developed by Automattic designed to help developers and users quickly generate custom WordPress blocks.

Telex is an experimental AI programming tool developed by Automattic, the parent company of WordPress, primarily aimed at assisting developers and site builders in creating custom Gutenberg blocks. Users only need to describe the desired block structure, style, and interaction through everyday natural language prompts, and Telex can automatically generate runnable WordPress block components within just a few tens of seconds.

This tool is deeply integrated with the WebAssembly-based WordPress Playground serverless sandbox environment, allowing generated code to be previewed and tested for front-end effects and editor backend in the browser without requiring a local development environment. Telex also offers conversational iterative functionality, enabling users to make multiple code refinements through interactions with the AI assistant. The final generated block can be packaged and exported as a standard .zip format plugin with one click, facilitating seamless installation on self-hosted WordPress websites.

Features List

  • Natural Language Code Generation: Supports describing component logic and appearance using plain text prompts, with AI converting them into native WordPress Gutenberg block code.
  • Built-in Playground Sandbox Preview: Seamlessly integrates WordPress Playground, allowing users to view real-time block rendering and backend parameter settings.
  • Conversational Continuous Iteration: Users can issue specific modification commands to the initial block version through the sidebar AI assistant, which understands and updates the code accordingly.
  • One-Click Plugin Packaging and Export: Supports compressing completed blocks along with dependent code into a standard WordPress plugin ZIP package.
  • Native Compatibility Architecture: Generated code follows official block editor development specifications, ensuring compatibility under various themes.
  • Code Visualization and Review: Allows developers to view the underlying source code written by AI, ensuring logical transparency.
  • Visual Reference Image Parsing (Gradually Opened): Supports users uploading UI screenshots or wireframes to help more accurately restore designs.

User Guide

Welcome to Telex! This AI programming platform created by Automattic can directly convert your textual ideas into fully functional native WordPress blocks. To help you maximize the platform’s productivity, a detailed operation guide is prepared below.

Special Note: Since Telex is currently in an experimental phase, to ensure a complete code generation and rendering experience, it is currently mandatory to use a desktop browser, as mobile devices cannot open the main workspace.

1. Account Registration and Workspace Access

  1. Access the platform: Open a recommended desktop browser (such as Google Chrome or Microsoft Edge) and visit the official site at https://telex.automattic.ai/.
  2. Account login and authorization: Click the “Sign In” button on the homepage. Telex uses the WordPress.com account system for single sign-on (SSO). Existing users may authorize directly; new users can register for free.
  3. Enter the console: After login, a simple prompt dialog window will appear as the starting point for code generation.

2. Core Operation Flow: From Prompt to Usable Plugin

Step 1: Writing High-Quality Prompts

The accuracy of code generation depends on the detail in your description. It is recommended to construct prompts with “function definition + backend configuration + visual style + interaction effects.”

  • Example requirement: Create a “Team Member Introduction” block.
  • Recommended prompt: “Please generate a ‘Team Member Showcase’ Gutenberg block. Support display of three members per row. Backend configuration: Allow uploading avatars, filling in names, positions, and bios. Visual style: Minimalist, avatars are circular with gray shadows. Interaction: On mouse hover, the card elevates 5px and displays LinkedIn and Twitter icons.”
  • Submit: After confirming your description, press Enter or click the send icon to start generation.

Step 2: Code Generation and Sandbox Verification

  • Visual generation: After the command is issued, the system will show the code generation progress, usually taking 30 seconds to 1 minute.
  • WordPress Playground loading: Once the code is completed, Telex will launch a serverless WordPress sandbox for immediate testing.
  • Dual view toggle:
    • Editor view: Simulates WordPress editing interface, allowing users to test the generated block and its attribute panel.
    • Frontend view: Displays the block’s visual effects and animations on a webpage.

Step 3: Conversing with AI Assistant for Iteration

  • Invoke the assistant: Click “Assistant” in the right sidebar to enter conversation mode.
  • Send modification instructions: Simply describe the parts you want to change.
  • Automatic updates: AI will edit relevant code parts based on your requests, refreshing the sandbox upon completion.

Step 4: Packaging, Exporting, and Deployment

Once debugging the block is complete, it can be migrated to an actual site.

  1. Export ZIP package: Click the “Download” or “Export” button; the system compresses all dependent files into a ZIP package.
  2. Upload to personal site: Log in to your WordPress backend.
  3. Install and activate: Choose Plugins -> Add New -> Upload Plugin in the menu to install the downloaded ZIP file.
  4. Real usage: Search for and add the block in the block editor.

3. Advanced Tips and Pitfall Avoidance

  • Code review mode: Developers can view the underlying source code and guide the AI to fix complex issues.
  • Modular principle: It is recommended to split large projects into multiple independent functional blocks to improve success rate and code quality.
  • Handling generation failure: If rendering fails, try regenerating or simplifying prompts.

Application Scenarios

  1. Rapid prototyping and demonstration: Web designers and product managers can directly use Telex to display interaction effects.
  2. Customized marketing activity component development: E-commerce teams can quickly generate blocks with specific visual styles, saving time and costs.
  3. Assist WordPress developers in improving efficiency: Telex serves as a code co-pilot, helping developers focus on core logic.
  4. Feature expansion for no-code site builders: Users can customize exclusive components via natural language, breaking functional limitations.

QA

  1. Is Telex a paid tool? Answer: Currently, Telex is completely free; paid plans may be introduced in the future.
  2. Can the generated blocks be installed directly? Answer: As long as it is a self-hosted WordPress site that supports plugin installation, the ZIP file exported by Telex can be used directly.
  3. Can Telex generate complete WordPress themes? Answer: No, Telex focuses on generating Gutenberg blocks.
  4. Why can’t Telex be opened on mobile phones? Answer: A desktop browser is required to ensure system stability.
  5. How to fix bugs in generated blocks? Answer: Open the AI assistant, describe the issues, and the AI will automatically correct the code and display the modifications.
