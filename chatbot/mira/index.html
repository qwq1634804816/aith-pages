Mira：An AI Library for Automating Company Research and Analysis

github.com/DimiMikadze/Mira

Mira is an AI library focused on automating company research, providing flexible data collection and analysis capabilities.

Mira is an AI library for company research that can automatically perform research tasks. Users only need to provide a company’s official website, and Mira will launch a system composed of multiple specialized AI agents that collaborate. These agents are responsible for discovering and scraping company pages, analyzing publicly available LinkedIn data, and integrating Google search results. They can automatically extract key information, validate external sources, and ultimately generate structured company profiles, each with sources and credibility scores to ensure transparency and reliability of information. The core architecture of Mira is independent of the development framework and can be easily integrated as an npm package into existing applications. In addition, the project also provides a front-end example application based on Next.js to help users better understand and utilize it.

Feature List

  • Multi-Agent Architecture: The system is designed with multiple specialized agents that handle company information discovery, webpage scraping, and comprehensive analysis, ultimately outputting a unified company profile.
  • Flexible and Customizable: Users can easily adjust agent behavior, scraping data points, and designing prompts to suit specific workflows or research needs.
  • Real-Time Progress Feedback: During research tasks, the system will emit structured events for users to track task progress in real-time.
  • Confidence Scoring and Source Verification: Each extracted piece of information is labeled with a credibility score and its source, ensuring research transparency.
  • Company Standard Matching: Can evaluate target companies based on user-defined criteria, providing match scores and detailed analysis rationale.
  • Built-in Data Collection Service: Integrates services for web scraping, Google search, and LinkedIn data, supporting automated handling of cookie consent.
  • Intelligent Task Coordination: The system can automatically coordinate tasks among various agents, merge results, and manage data sources.
  • Composable Core Library: This core library is independent of specific development frameworks, making it easy to use in any Node.js or TypeScript project.
  • Sample Front-End Interface: The project comes with a sample website based on Next.js, demonstrating how to use the core library and providing a simple running interface.

Usage Help

Mira is a powerful tool, and the project also provides a complete front-end application that allows users to easily run and test locally. Users can utilize Mira in the following two ways.

1. Run the Complete Application with Front-End Locally

This method is suitable for developers who want to quickly experience Mira’s features.

Environment Requirements:

  • Node.js (version 18 or higher)
  • npm (usually installed along with Node.js)
  • OpenAI API Key
  • ScrapingBee API Key

Installation Steps:

  1. Clone the Repository Use the following command to clone the project code to your local:
   git clone https://github.com/dimimikadze/mira.git
  1. Navigate to the Project Folder and Install Dependencies Enter the cloned directory and install the required dependencies via npm:
   cd mira
   npm install
  1. Configure Environment Variables Sensitive information like API keys should be configured via environment variables. Create a .env.local file located in the packages/mira-frontend/ directory. Execute the following command to quickly create and edit:
   # Please execute this command in the project root directory (mira/)
   touch packages/mira-frontend/.env.local

Open this file in a code editor and fill in the API keys in the format:

   OPENAI_API_KEY=sk-xxxx
   SCRAPING_BEE_API_KEY=xxxx

Ensure to replace sk-xxxx and xxxx with actual keys. 4. Run the Front-End Application After completing the above steps, use the following command to start the development server:

   npm run dev:mira-frontend

Upon successful startup, the terminal will display a local URL (usually http://localhost:3000). Visit this URL in your browser to enter the Mira operating interface.

2. Use as an NPM Package in Your Project

If you want to integrate Mira’s automation research capabilities into other applications, it can be used directly as an npm package.

Installation:

In Node.js or TypeScript projects, use the following command to install the mira-ai core library:

   npm install mira-ai

Usage Method:

After installation, import the researchCompany function in your code to call Mira’s core functionality. Here is a basic usage example:

import { researchCompany } from "mira-ai";
async function runResearch() {
  // Configure API keys
  const config = {
    apiKeys: {
      openaiApiKey: process.env.OPENAI_API_KEY,
      scrapingBeeApiKey: process.env.SCRAPING_BEE_API_KEY,
    },
  };  
  // Define research parameters and callback function
  const options = {
    // Provide custom company criteria for AI evaluation
    companyCriteria: "Companies in the B2B SaaS field with more than 50 employees",
    // onProgress is the callback function for receiving real-time progress updates
    onProgress: (event) => {
      console.log("Real-time progress event:", event);
    },
  };
  try {
    const result = await researchCompany("https://www.example.com", config, options);
    console.log(result);
  } catch (error) {
    console.error("An error occurred during the research process:", error);
  }
}
// Ensure that the environment variables OPENAI_API_KEY and SCRAPING_BEE_API_KEY are set up before running
runResearch();

In the example, the researchCompany function takes three parameters: the company website, a configuration object containing API keys, and optional parameters. By using the onProgress callback, a real-time user interface can be built to display the research progress.

Frequently Asked Questions

  1. What is Mira? How is it different from a regular chatbot?: Mira is an AI library that actively collaborates to collect information, as opposed to a chatbot that answers questions.
  2. What API keys are needed to use Mira?: Two API keys are required: OPENAI_API_KEY and SCRAPING_BEE_API_KEY, the former for AI inference and the latter for web scraping support.
  3. Can Mira customize the information it collects?: Yes, Mira is designed to be flexible, allowing users to customize agents and data points to scrape.
  4. Can Mira be integrated into existing CRM systems?: Yes, through API calls, Mira-generated research reports can be easily integrated into CRM systems.
