SQLBot：An Intelligent Bot that Converts Natural Language into SQL Queries

github.com/dataease/SQLBot

SQLBot is an intelligent data query system that helps users retrieve data using natural language.

SQLBot is an intelligent data query system that combines large language models (LLM) with retrieval-augmented generation (RAG) technology. As a module of the open-source business intelligence (BI) tool DataEase, it aims to solve the problem of ordinary business users being unable to directly access data from databases due to unfamiliarity with SQL language. Users can ask questions in everyday language, and SQLBot can understand the intent, automatically generate the corresponding SQL query code, and return results or visualized charts. This tool supports out-of-the-box use, requiring only simple configuration of the large model and data source to start, and is easy to integrate, capable of being embedded into various third-party business systems, empowering them with conversational data analysis. In addition, SQLBot provides workspace-based resource isolation and fine-grained data permission control to ensure the security of the data query process.

功能列表

  • Natural Language to SQL: Automatically converts user’s natural language questions into Structured Query Language (SQL).
  • RAG Enhancement: Integrates RAG technology to improve the accuracy of SQL generation in specific data environments.
  • Data Source Support: Supports connections to various mainstream databases, such as MySQL.
  • Model Management: Supports access and management of multiple large language models, allowing users to configure and switch based on needs.
  • Permission Control: Provides workspace-level resource isolation and fine-grained data permission management to ensure data security.
  • Easy Integration: Can be quickly embedded into third-party systems as a plug-in or module and supports integration with AI development platforms like n8n, Dify, Coze, etc.
  • Out-of-the-Box: Provides one-click installation scripts and Docker deployment methods, simplifying deployment and configuration processes.

使用帮助

The installation and usage process of SQLBot is quite straightforward and mainly consists of four steps: environment preparation, service startup, initial configuration, and usage.

1. Environment Preparation and Installation

Before installing SQLBot, ensure that your server has Docker and Docker Compose installed, as these are the foundations for containerized deployment.

Once the preparation work is completed, you can install with the following command:

  1. Create Installation Directory and Enter
    Choose a suitable location on your Linux server, such as /opt/sqlbot, and create that directory.

    mkdir -p /opt/sqlbot
    cd /opt/sqlbot

  2. Download Configuration File
    Use the curl command to download the docker-compose.yaml file from the official GitHub repository, which defines the SQLBot service and its dependent environment.

    curl -o docker-compose.yaml https://raw.githubusercontent.com/dataease/SQLBot/main/docker-compose.yaml

  3. Start the Service
    Execute the following command; Docker Compose will automatically pull the image and start the SQLBot service based on the configuration file. The -d parameter indicates to run in the background.

    docker compose up -d

2. Access and Login

After the service starts, you can access the deployed server’s IP address and 8000 port in your browser: http://<your server IP>:8000/.
The default administrator account information for the system is as follows:

  • Username: admin
  • Password: SQLBot@123456
    Please change the default password after logging in for the first time.

3. Core Configuration

After successfully logging in, two core configurations are required to start using the intelligent query feature: Configure Large Model and Add Data Source.

  1. Configure Large Model

    • After logging in, find the “Model Management” menu.
    • Click “New” or “Add Model” and select the large language model to use (e.g., GPT, Wenxin Yiyuan, Tongyi Qianwen, etc.).
    • Fill in the model’s API Key, Base URL, and other authentication information, then click save to add the model. You can add multiple models and set one as the default query model.

  2. Add Data Source

    • Switch to the “Data Source” menu and click “New Data Source.”
    • Choose the type of data source from the supported database types (e.g., “MySQL”).
    • Fill in the connection information, including name, hostname/IP address, port, database name, and the username and password used for authentication.
    • Click “Test” to test the connection; after successful connection, click “Save”.

4. Start Intelligent Querying

After completing the above configurations, you can start using it:

  • Go to the Q&A interface (usually “Chat” or “Q&A”).
  • In the input box, describe the data to be queried in natural language, for example: “Help me find the top five products with the highest sales from last month.”
  • SQLBot will process the question, generate the SQL statement, and automatically execute the query.
  • The query results will be displayed directly in the form of tables, cards, or charts, making it easy to gain quick insights from the data.

应用场景

  1. Self-Service Data Analysis for Business Personnel
    Employees in positions such as marketing, operations, and sales usually do not have the ability to write SQL. SQLBot enables them to query and analyze data through natural language questions, significantly enhancing the efficiency of data-driven decision-making.

  2. Rapid Data Exploration
    Data analysts frequently need to write different dimension queries during exploratory data analysis (EDA). Through SQLBot, analysts can quickly verify data hypotheses and focus more on data insights rather than code writing.

  3. Embedded Analytics
    SQLBot’s Q&A capabilities can be integrated into existing business systems (e.g., CRM, ERP), allowing users to query relevant data directly through a dialogue window while using these systems, achieving seamless integration of data analysis capabilities and business processes.

QA

  1. What types of large models does SQLBot support?
    SQLBot is designed to be open and supports the integration of major large language models in the market, including OpenAI’s GPT series, Baidu’s Wenxin Yiyuan, Alibaba’s Tongyi Qianwen, etc. It can also integrate open-source models deployed locally through tools like Ollama.

  2. Does SQLBot need to be installed with DataEase first?
    SQLBot is part of the DataEase ecosystem, and the best experience is achieved when used together. However, it can also be deployed independently and integrated as a system.

  3. How is the accuracy of generated SQL ensured?
    SQLBot utilizes RAG technology. Before sending user questions to the large model, the system retrieves information related to the question from the database metadata and provides it to the large model, thereby improving the ability to generate more accurate SQL.

  4. How is data security ensured?
    SQLBot provides workspace-level resource isolation, ensuring that data sources and query histories in different workspaces are isolated from each other. Administrators can also implement fine-grained data permission control, ensuring users can only query data within their permission scope to avoid data leakage.
