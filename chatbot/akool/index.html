Installation and Registration

  1. Visit the AKOOL official website: https://akool.com/
  2. Click the “Login” button in the upper right corner and select “Register” to create a new account.
  3. Fill in the necessary personal information and confirm registration.
  4. After logging in, choose the subscription plan that best suits you: Pro, Max, or Enterprise.

Function Operation Guide

Face Replacement

  1. After logging in, select the “Face Replacement” feature.
  2. Upload the image or video you want to replace the face of.
  3. Choose a face template; you can select movie characters, gender conversion, etc.
  4. Click “Start Replacement,” and after the AI processing is complete, download the result.

Video Translation

  1. Select the “Video Translation” feature.
  2. Upload the video file that needs translation.
  3. Choose the target language; the system will automatically translate and sync lip movements.
  4. Once completed, you can preview and download the translated video.

Image Generation

  1. Select the “Image Generation” feature.
  2. Enter a prompt describing the image, such as “city skyline at sunset.”
  3. Click “Generate Image,” and the AI will create the image based on it.
  4. You can fine-tune the generated image and download the final result.

Virtual Human

  1. Select the “Virtual Human” feature.
  2. Enter the text the virtual human should say or upload a text file.
  3. Choose appearance and voice, and the system generates the video.
  4. Preview and download the generated video.

Talking Photos

  1. Select the “Talking Photos” feature.
  2. Upload a photo.
  3. Input the text for the person to say and choose the voice type.
  4. The system-generated talking photo is available for preview and download.

Background Replacement

  1. Select the “Background Replacement” feature.
  2. Upload a product photo.
  3. Choose or upload a new background image.
  4. The system will automatically identify and replace the background, allowing you to preview and download the final effect.
