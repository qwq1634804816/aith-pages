FaceFusion is a cloud platform that integrates facial swapping and enhancement functions, providing various AI face-swap solutions.

FaceFusion is an advanced cloud platform that combines facial swapping and enhancement functions, optimizing the “image to video” and “image to image” swapping processes. It includes five specialized models to ensure perfect output quality. Usage Help

Installation Guide

Deploy FaceFusion3 locally on Win11, integrated with TensorRT10.4 for accelerated inference.

The installation of FaceFusion requires a certain technical foundation. Users familiar with the command line can follow these steps:

FaceFusion3.0.0 is currently the strongest AI face-swapping project. Below is how to locally deploy this project based on the latest CUDA12.6 and cuDNN9.4 on Win11 and integrate it with TensorRT10.4 to enhance inference speed and efficiency.

Install the Latest Version of CUDA12.6 and cuDNN9.4

CUDA is a technology developed by NVIDIA that allows the GPU to participate in computing to accelerate processing. cuDNN is a toolbox optimized for deep learning. The installation package can be downloaded from the NVIDIA official website.

Double-click cuda_12.6.1_560.94_windows.exe to install, preferably in a non-C drive directory. After a successful installation, run the command to check if it is functioning normally:

(base) PS C:\Users\zcxey> nvcc -V

Next, open cudnn-windows-x86_64-9.4.0.58_cuda12-archive and copy the bin, include, and lib directories to the CUDA installation directory.

Install TensorRT10.4

TensorRT is an optimization tool for deep learning models. It enhances the inference speed of already trained models and reduces resource consumption. Copy all dynamic library DLL files from the lib directory of TensorRT to the bin directory of CUDA12.6.

Install and Deploy FaceFusion3.0.0

Ensure the Python3.11 development environment is installed, then clone the project:

git clone https://github.com/facefusion/facefusion.git
cd facefusion

Install the basic dependencies and onnxruntime-gpu:

pip3 install -r requirements.txt
pip3 install onnxruntime-gpu

Note that the default version of onnxruntime-gpu is 19.2, specifically tailored for CUDA12.

Install the TensorRT library:

pip3 install tensorrt==10.4.0 --extra-index-url https://pypi.nvidia.com

Finally, install torch:

pip3 install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124

Once installed successfully, enter the Python3.11 terminal:

>>> import onnxruntime as ort  
>>> print(ort.get_available_providers())  
['TensorrtExecutionProvider', 'CUDAExecutionProvider', 'CPUExecutionProvider']

If three backend supports are output, the configuration is successful.

Run the command to start:

python3 facefusion.py run

Enter the main face-swapping interface:

With TensorRT, real-time face swapping is supported; enter the webcam face swap interface:

python3 facefusion.py run --ui-layouts webcam

It should be noted that FaceFusion3.0.0 requires the local installation of ffmpeg software:

winget install -e --id Gyan.FFmpeg

For users unfamiliar with the command line, FaceFusion provides a Windows installer for quick setup.

Usage Guide

Basic Operations

  1. Start FaceFusion:
python run.py
  1. Select source image: Upload the image you want to replace the face.
  2. Select target image or video: Upload the image or video that needs the face replaced.
  3. Adjust parameters: Modify face detection, swapping models, enhancement settings, etc. as needed.
  4. Start processing: Click the “Start” button and wait for completion.

Advanced Features

  • Occlusion handling:
    • Enable the face_debugger option.
    • Select occlusion mode (box, occlusion, region).
    • Adjust the Face Mask Blur parameter to optimize effects.
  • HD processing:
    • Enable the face_enhancer option.
    • Choose suitable enhancement models like GFPGAN1.4 or codeformer.
    • Adjust Face Detector Size to improve detail handling capabilities.
  • Lip-sync:
    • Enable the lip_syncer option.
    • Upload audio files.
    • Select suitable lip-sync models.

Practical Tips

  • Performance optimization:
    • Choose the appropriate Execution Provider according to the graphics card.
    • Adjust Execution Thread Count to balance speed and memory usage.
  • Multi-face processing:
    • Use Face Selector Mode to choose to process a single or multiple faces.
    • Adjust Reference Face Distance to improve matching accuracy.
  • Cartoon face processing:
    • Use the simswap_256 model for cartoon face replacement.
    • Enable face_enhancer and focus on enhancing the eyes, nose, and mouth.

Frequently Asked Questions

  • Does FaceFusion support real-time processing? Currently optimized mainly for offline processing, but speed can be improved through parameter adjustments.
  • How can I improve the naturalness of the face-swapping effect? Adjust the Face Mask Blur parameter, use high-quality source images, and enable face_enhancer to further enhance the effect.
  • Does FaceFusion support batch processing? Yes, it supports batch processing for images and videos.
