Xianyu Auto Reply System：Xianyu Intelligent Customer Service and Product Auto Delivery Tool

www.kdjingpai.com/xianyu-auto-reply/

This article introduces the features and usage methods of the Xianyu auto reply system to help sellers manage their Xianyu shops efficiently.

The Xianyu auto reply system is an automatic customer service and management tool specially developed for the Xianyu platform, built using Python and FastAPI, and hosted on GitHub. Through WebSocket, the system can connect to the Xianyu server in real-time, thereby automatically responding to buyer messages, delivery, and product management. It supports multi-user and multi-account operations, while providing keyword matching, intelligent replies, and automatic delivery functions, making it particularly suitable for sellers who need to manage their shops efficiently. The project is an open-source version for learning and research purposes only and is strictly prohibited for commercial use.

Feature List

  • Multi-user Management: Supports user registration and login, ensuring data isolation and permission control.
  • Multi-account Support: Allows management of multiple Xianyu accounts, can independently monitor and perform bulk operations.
  • Intelligent Reply: Supports keyword matching, product-specific replies, and AI intelligent replies (requires configuration of OpenAI API).
  • Automatic Delivery: Automatically sends cards or texts based on product information matching rules, supports delayed delivery.
  • Product Management: Automatically collects product information, supports multiple specifications and batch editing.
  • Product Search: Obtains real Xianyu product data through Playwright and sorts based on the quantity of ‘user interest’.
  • System Monitoring: Provides real-time logs, performance monitoring, and service health check functions.
  • Data Management: Supports keyword import/export in Excel format and automatically backs up data.

Usage Instructions

Installation Process

According to the official guide, the system provides three deployment methods: Docker one-click deployment, Docker Compose deployment, and local deployment. Here are the detailed steps:

Method 1: Docker One-click Deployment (Recommended for Beginners)

  1. Create Data Directory:
   mkdir -p xianyu-auto-reply
  1. Start Container:
docker run -d -p 8080:8080 -v $PWD/xianyu-auto-reply/:/app/data/ --name xianyu-auto-reply --privileged=true registry.cn-shanghai.aliyuncs.com/zhinian-software/xianyu-auto-reply:1.0
  1. Access System: Open the browser and enter http://localhost:8080.
  2. Troubleshooting:
    • If there is a port conflict, please change 8080 to another port.
    • Ensure that Docker Desktop is running; Linux systems may require using sudo.

Method 2: Docker Compose Deployment (Recommended)

  1. Clone the Project:
   git clone https://github.com/zhinianboke/xianyu-auto-reply.git
   cd xianyu-auto-reply
  1. Run Deployment Script:
   ./docker-deploy.sh
  1. Access System: Enter http://localhost:8080.
  2. Troubleshooting: Refer to DOCKER_FIX.md to check the docker-compose.yml port configuration.

Method 3: Local Deployment

  1. Clone the Project:
   git clone https://github.com/zhinianboke/xianyu-auto-reply.git
   cd xianyu-auto-reply
  1. Install Dependencies:
   pip install -r requirements.txt

Please ensure that Python 3.11 or above is installed. 3. Install Playwright (needed for product search functionality):

   playwright install chromium
  1. Start System:
   python Start.py
  1. Access System: Enter http://localhost:8080.

Configure Admin Password

  • Default admin account: Username admin, Password admin123.
  • Change Password: Please change the password on the user management page after the first login to ensure security.
  • Configuration is stored in global_config.yml, where you can set WebSocket, API, reply rules, etc.

Functional Operation Process

1. User Registration and Login

  • Operation Steps:
    1. Visit http://localhost:8080/register.html.
    2. Fill in your email and complete the CAPTCHA verification.
    3. Enter the image verification code to complete registration.
    4. Log in at http://localhost:8080/login.html using the registered email and password.
  • Security Features: The system uses JWT authentication for data isolation to prevent brute-force attacks.

2. Add Xianyu Account

  • Operation Steps:
    1. After logging in, go to the main interface and click ‘Add New Account’.
    2. Enter the Xianyu account ID and Cookie value (can be obtained through QR code login).
    3. The system will automatically start monitoring the account and display the connection status.
  • Batch Operations: Supports starting or stopping multiple account tasks simultaneously.
  • Note: Regularly update cookies to avoid expiration.

3. Configure Automatic Replies

  • Keyword Matching:
    1. Go to the ‘Data Management’ page, add keywords and reply content.
    2. Example: Keyword “price”, reply “The product price is XX yuan”.
    3. Supports product-specific keywords and global general keywords, with priority: specific > general > AI reply.
  • AI Intelligent Reply:
    1. Enter the OpenAI API key in the settings page and select a model (e.g., GPT-3.5).
    2. Configure prompt words and enable AI replies.
    3. The system will generate intelligent replies based on context, supporting dynamic variables (like username).
  • Excel Import/Export:
    1. Download the Excel template provided by the system.
    2. Fill in keywords and replies, then upload to ‘Data Management’ page.
    3. The system will validate data format and automatically import.

4. Set Up Automatic Delivery

  • Operation Steps:
    1. Go to the ‘Delivery Management’ page, add delivery rules.
    2. Set product keywords and delivery content (text or card file).
    3. Configure delay delivery time (0-3600 seconds).
    4. The system will automatically match rules for delivery upon detecting payment messages.
  • Multiple Specifications Support: Can automatically match product specifications, and failover to regular cards when needed.
  • Duplicate Prevention Mechanism: Avoids duplicate deliveries and confirmations.
  • Delivery Statistics: Can view delivery records and statistical data.

5. Product Management

  • Operation Steps:
    1. The system can automatically collect product information from messages.
    2. Obtain complete product details through the Xianyu API.
    3. Edit or manage products in bulk on the ‘Product Management’ page.
  • Multiple Specifications Support: Manage information of products with different specifications.
  • Intelligent Deduplication: Avoids duplicate storage of product data.

6. Product Search

  • Operation Steps:
    1. After logging in, go to the ‘Product Search’ page.
    2. Enter keywords and pagination number; the system will fetch real data through Playwright.
    3. Products are sorted by ‘user interest’ quantity, with the ability to view details.
  • Frontend Pagination: Flexibly displays multi-page product data.

7. System Monitoring

  • Real-time Logs: View operation logs on the ‘Log Management’ page.
  • Performance Monitoring: Check system resource usage.
  • Health Check: Ensure the service operates normally.

Notes

  • Security: Do not hardcode Cookies or passwords; it is recommended to use a .env file for storage.
  • Compliance: Please abide by Xianyu platform regulations to avoid account restrictions from frequent operations.
  • Log Management: Regularly clean up log files in the logs/ directory to free up space.
  • Data Backup: The system will automatically back up data to the mounted directory; regular checks are needed.

Application Scenarios

  1. Individual Xianyu Sellers: Small-scale sellers can quickly respond to buyer inquiries through automatic replies and delivery functions, improving transaction rates.
  2. Multi-account Operators: Users managing multiple Xianyu accounts can uniformly monitor messages and products, simplifying processes.
  3. Night-time Customer Service Needs: The system supports 24/7 automatic replies, suitable for sellers who cannot handle manual processing at night.
  4. Batch Product Management: Sellers selling various products can efficiently handle orders using product management and automatic delivery functions.
  5. Data Analysis Needs: Sellers can analyze market demand and sales through product search and log statistics features.

QA

  1. Is the tool free?: The project is open-source, free for learning and research, and prohibited for commercial use.
  2. Which AI models are supported?: Supports OpenAI’s GPT-3.5, GPT-4, and Tongyi Qianwen, requiring API key configuration.
  3. How to avoid account bans?: Set reasonable reply intervals, follow Xianyu regulations, and update Cookies regularly.
  4. Does the product search function require additional configuration?: Playwright and Chromium need to be installed; Docker deployment includes them.
  5. How to view system logs?: View real-time logs on the ‘Log Management’ page or check the files in the logs/ directory.
