安装与注册

  1. 访问AKOOL官网：https://akool.com/
  2. 点击右上角“登录”按钮，选择“注册”以创建新账户。

功能操作指南

面部替换

  1. 登入后选择“面部替换”功能。
  2. 上传希望替换面部的图片或视频。
  3. 选择面部模板，您可选电影角色、性别转换等。
  4. 点击“开始替换”，待AI处理完成后下载结果。

视频翻译

  1. 选择“视频翻译”功能。
  2. 上传需要翻译的视频文件。
  3. 选择目标语言，系统会自动翻译并同步口型。
  4. 完成后可预览并下载翻译后的视频。

图像生成

  1. 选择“图像生成”功能。
  2. 输入描述图像的提示，例如“日落下的城市天际线”。
  3. 点击“生成图像”，AI会据此生成图像。
  4. 可微调生成的图像并下载最终结果。

虚拟人

  1. 选择“虚拟人”功能。
  2. 输入虚拟人要说的话或上传文本文件。
  3. 选择外观和声音，系统生成视频。
  4. 预览并下载生成的视频。

会说话的照片

  1. 选择“会说话的照片”功能。
  2. 上传一张照片。
  3. 输入人物要说的话，选择声音类型。
  4. 系统生成的会说话照片可供预览和下载。

背景更换

  1. 选择“背景更换”功能。
  2. 上传产品照片。
  3. 选择或上传新的背景图像。
  4. 系统自动识别并替换背景，最终效果可预览和下载。
