SQLBot：将自然语言转换为SQL查询的智能机器人

github.com/dataease/SQLBot

SQLBot是一款智能数据查询系统，帮助用户通过自然语言获取数据。

SQLBot 是一个结合大型语言模型（LLM）与检索增强生成（RAG）技术的智能数据查询系统。作为开源商业智能（BI）工具 DataEase 的一个模块，它致力于解决普通业务人员因对SQL语言不熟悉而无法直接从数据库获取数据的问题。用户可以用日常语言提出问题，SQLBot 可以理解意图，自动生成相应的SQL查询代码，并返回结果或可视化图表。该工具支持开箱即用，只需简单配置大模型和数据源便可启动，同时易于集成，能够嵌入到各种第三方业务系统，为这些应用赋能对话式数据分析。此外，SQLBot 提供基于工作空间的资源隔离及细粒度的数据权限控制，确保数据查询过程的安全性。

功能列表

  • 自然语言转SQL：将用户的自然语言提问自动转换为结构化查询语言(SQL)。
  • RAG增强：集成RAG技术，提升特定数据环境中生成SQL的准确性。
  • 数据源支持：支持连接多种主流数据库，如 MySQL。
  • 模型管理：支持接入并管理多种大型语言模型，用户可根据需求配置和切换。
  • 权限控制：提供工作空间级别的资源隔离和细粒度的数据权限管理，以保障数据安全。
  • 易于集成：可作为插件或模块快速嵌入到第三方系统，并支持与n8n、Dify、Coze等AI开发平台集成。
  • 开箱即用：提供一键安装脚本和Docker部署方式，简化了部署和配置流程。

使用帮助

SQLBot的安装和使用流程相当直接，主要分为环境准备、服务启动、初始配置和使用四个步骤。

1. 环境准备与安装

在安装SQLBot之前，确保您的服务器已安装 Docker 和 Docker Compose ，这两者是容器化部署的基础。

完成准备工作后，您可以通过以下命令一键安装：

  1. 创建安装目录并进入
    在您的 Linux 服务器上选择一个适合的位置，如 /opt/sqlbot 并创建该目录。

    mkdir -p /opt/sqlbot
    cd /opt/sqlbot

  2. 下载配置文件
    使用 curl 命令从官方GitHub仓库下载 docker-compose.yaml 文件，该文件定义了SQLBot服务和其依赖环境。

    curl -o docker-compose.yaml https://raw.githubusercontent.com/dataease/SQLBot/main/docker-compose.yaml

  3. 启动服务
    执行下列命令，Docker Compose 将根据配置文件自动拉取镜像并启动 SQLBot 服务。 -d 参数表示在后台运行。

    docker compose up -d

2. 访问和登录

服务启动后，您可以在浏览器中访问部署服务器的IP地址和 8000 端口： http://<您的服务器IP>:8000/。
系统的默认管理员账号信息如下：

  • 用户名: admin
  • 密码: SQLBot@123456
    首次登录后请修改默认密码。

3. 核心配置

成功登录后，需进行两个核心配置以开始使用智能问数功能：配置大模型 和 添加数据源。

  1. 配置大模型

    • 登录后，找到“模型管理”菜单。
    • 点击“新建”或“添加模型”，选择需要使用的大语言模型（例如 GPT、文心一言、通义千问等）。
    • 填写模型的 API Key、Base URL 等认证信息，后点击保存以添加模型。可添加多个模型，并设置一个为默认查询模型。

  2. 添加数据源

    • 切换到“数据源”菜单，点击“新建数据源”。
    • 从支持的数据库类型中选择数据源类型（如“MySQL”）。
    • 填写连接信息，包括名字、主机名/IP地址、端口、数据库名，以及用于认证的用户名和密码。
    • 点击“检验”测试连接成功后，点击“保存”。

4. 开始智能问数

完成上述配置后，即可开始使用：

  • 进入问答界面（通常是“对话”或“Q&A”）。
  • 在输入框中用自然语言描述要查询的数据，例如：“帮我查一下上个月销售额最高的前五个产品。”
  • SQLBot 将处理问题，生成SQL语句，并自动执行查询。
  • 查询结果会以表格、卡片或图表形式直接展示，便于快速获取数据洞察。

应用场景

  1. 业务人员的自助数据分析
    对于市场、运营、销售等岗位的员工，他们通常不具备编写SQL的能力。SQLBot使他们能通过自然语言向数据库提问，实现数据的自助查询与分析，大幅提升数据驱动决策效率。

  2. 快速数据探索
    数据分析师在进行探索性数据分析（EDA）时，需要频繁编写不同维度的查询语句。通过SQLBot，分析师能快速验证数据假设，更专注于数据洞察而非代码编写。

  3. 嵌入式分析
    SQLBot的问答能力可以集成到现有的业务系统（如CRM、ERP）中，用户在使用这些系统时，无需切换到专门BI平台，直接通过对话窗口查询相关数据，实现数据分析能力与业务流程的无缝融合。

QA

  1. SQLBot支持哪些类型的大模型？
    SQLBot设计为开放的，支持接入市场上主要的大语言模型，包括OpenAI的GPT系列、百度的文心一言、阿里的通义千问等，也可接入通过Ollama等工具在本地部署的开源模型。

  2. 使用SQLBot是否必须先安装DataEase？
    SQLBot是DataEase生态的一部分，最佳体验是结合使用，但它本身也是可以独立部署并集成的系统。

  3. 如何保证生成SQL的准确性？
    SQLBot利用RAG技术，在将用户问题发送至大模型前，系统会从数据库元数据中检索出与问题关联的信息，提供给大模型，从而提升生成更准确的SQL的能力。

  4. 数据安全如何保障？
    SQLBot提供工作空间级别的资源隔离，不同空间的数据源及问答历史相互隔离，且管理员可进行细粒度数据权限控制，确保用户仅能查询到权限范围内的数据，避免数据泄露。
