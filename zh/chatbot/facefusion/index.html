FaceFusion：视频换脸增强工具|语音同步视频嘴型动作

www.kdjingpai.com/facefusion/

FaceFusion是一个集成面部交换与增强功能的云平台，提供多种AI换脸解决方案。

FaceFusion是一个结合了面部交换和强化功能的先进云平台，优化了“图像到视频”以及“图像到图像”的交换流程，包含五个专业模型，以确保输出质量完美。此外，它还通过七种模型进行面部增强，运用三种不同的模型提升视频和图像质量，提供了一系列强大的功能，如人脸替换、增强和唇形同步等。

FaceFusion旨在为用户提供一个简单、高效且功能丰富的AI换脸解决方案。它支持在线操作以及多模型人脸检测等功能。GitHub项目提供安装和使用指南，但需要一定的技术知识。

FaceFusion版本更新至3.0，优化显著，建议用户更新。文章末尾提供多种一键安装包。若电脑无法运行，可选择更多优秀的免费在线换脸工具。换脸工具。

使用帮助

安装指南

在Win11上本地部署FaceFusion3，集成Tensorrt10.4加速推理。

FaceFusion的安装需要一定的技术基础。熟悉命令行的用户可以按照以下步骤操作：

FaceFusion3.0.0是当前最强的AI换脸项目。下面是如何在Win11系统上基于最新的cuda12.6及cudnn9.4本地部署该项目，并与Tensorrt10.4结合，以提高推理速度和效率。

安装最新版本Cuda12.6及Cudnn9.4

CUDA是NVIDIA开发的技术，能让GPU参与计算以加速处理。cuDNN则是深度学习优化的工具箱。安装包可从NVIDIA官方网站下载。

直接双击cuda_12.6.1_560.94_windows.exe进行安装，建议选择非C盘目录。成功安装后，运行命令检查是否正常：

(base) PS C:\Users\zcxey> nvcc -V

Built on Wed_Aug_14_10:26:51_Pacific_Daylight_Time_2024  
Cuda compilation tools, release 12.6, V12.6.68  
Build cuda_12.6.r12.6/compiler.34714021_0  
(base) PS C:\Users\zcxey>

接着打开cudnn-windows-x86_64-9.4.0.58_cuda12-archive，拷贝bin、include及lib目录至cuda的安装目录。

安装Tensorrt10.4

TensorRT是深度学习模型的优化工具。它能提升已经训练好的模型的推理速度和减少资源消耗。将TensorRT的lib目录下的所有动态库dll文件拷贝至cuda12.6的bin目录即可。

安装与部署FaceFusion3.0.0

确保有人安装Python3.11的开发环境，然后克隆项目：

git clone https://github.com/facefusion/facefusion.git
cd facefusion

安装基础依赖和onnxruntime-gpu：

pip3 install -r requirements.txt
pip3 install onnxruntime-gpu

注意，默认的onnxruntime-gpu版本是19.2，专为cuda12适配。

安装tensorrt库：

pip3 install tensorrt==10.4.0 --extra-index-url https://pypi.nvidia.com

最后，安装torch：

pip3 install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124

成功安装后，进入Python3.11终端：

>>> import onnxruntime as ort  
>>> print(ort.get_available_providers())  
['TensorrtExecutionProvider', 'CUDAExecutionProvider', 'CPUExecutionProvider']

如输出三种后端支持，配置成功。

运行命令开始：

python3 facefusion.py run

进入换脸主界面：

通过Tensorrt支持实时换脸，进入摄像头换脸界面：

python3 facefusion.py run --ui-layouts webcam

摄像头换脸效果：

需要注意，FaceFusion3.0.0须本地安装ffmpeg软件：

winget install -e --id Gyan.FFmpeg

对不熟悉命令行的用户，FaceFusion提供Windows安装程序以快速完成安装。

使用指南

基本操作

  1. 启动FaceFusion：
python run.py
  1. 选择源图像：上传想替换人脸的图像。
  2. 选择目标图像或视频：上传需被替换人脸的图像或视频。
  3. 调整参数：根据需要调整面部检测、交换模型、增强设置等。
  4. 开始处理：点击“开始”按钮，等待完成。

高级功能

  • 遮挡处理：
    • 启用face_debugger选项。
    • 选择遮挡模式（box、occlusion、region）。
    • 调整Face Mask Blur参数优化效果。
  • 高清处理：
    • 启用face_enhancer选项。
    • 选择适合的增强模型，如GFPGAN1.4或codeformer。
    • 调整Face Detector Size提高细节处理能力。
  • 唇形同步：
    • 启用lip_syncer选项。
    • 上传音频文件。
    • 选择适合的唇形同步模型。

实用技巧

  • 性能优化：
    • 根据显卡选择合适的Execution Provider。
    • 调整Execution Thread Count以平衡速度和内存使用。
  • 多人脸处理：
    • 使用Face Selector Mode选择处理单个或多个人脸。
    • 调整Reference Face Distance提高匹配精度。
  • 卡通人脸处理：
    • 使用simswap_256模型进行卡通人脸替换。
    • 启用face_enhancer并重点增强眼睛、鼻子和嘴巴。

常见问题解答

  • FaceFusion支持实时处理吗？ 当前主要优化离线处理，但可通过参数调整提升速度。
  • 如何提高换脸效果的自然度？ 调整Face Mask Blur参数，并使用高质量源图像，同时启用face_enhancer可进一步改善效果。
  • FaceFusion是否支持批量处理？ 是的，支持图像和视频的批量处理。
