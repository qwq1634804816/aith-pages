闲鱼自动回复系统：闲鱼智能客服与商品自动发货工具

www.kdjingpai.com/xianyu-auto-reply/

本文介绍了闲鱼自动回复系统的功能及使用方法，以帮助卖家高效管理闲鱼店铺。

闲鱼自动回复系统是专为闲鱼平台开发的自动客服及管理工具，采用Python与FastAPI构建，托管于GitHub。通过WebSocket，该系统能够实时连接到闲鱼服务器，从而自动应对买家的消息、发货及商品管理。支持多用户和多账号操作，同时提供关键词匹配、智能回复及自动发货等多项功能，特别适合需要高效管理店铺的卖家。项目为开源版本，仅供学习和研究使用，严禁用于商业目的。

功能列表

  • 多用户管理：支持用户注册、登录，确保数据隔离与权限控制。
  • 多账号支持：允许管理多个闲鱼账号，可独立监控并进行批量操作。
  • 智能回复：支持关键词匹配、商品专用回复和AI智能回复（需配置OpenAI API）。
  • 自动发货：依据商品信息匹配规则，自动发送卡券或文本，支持延迟发货。
  • 商品管理：自动收集商品信息，支持多规格及批量编辑。
  • 商品搜索：通过Playwright获取真实闲鱼商品数据，并根据“人想要”的数量进行排序。
  • 系统监控：提供实时日志、性能监控和服务健康检查功能。
  • 数据管理：支持Excel格式的关键词导入导出，并自动备份数据。

使用帮助

安装流程

根据官方指南，该系统提供三种部署方式：Docker一键部署、Docker Compose部署和本地部署。以下是详细步骤：

方式一：Docker一键部署（推荐新手）

  1. 创建数据目录：
   mkdir -p xianyu-auto-reply
  1. 启动容器：
docker run -d -p 8080:8080 -v $PWD/xianyu-auto-reply/:/app/data/ --name xianyu-auto-reply --privileged=true registry.cn-shanghai.aliyuncs.com/zhinian-software/xianyu-auto-reply:1.0
  1. 访问系统： 打开浏览器，输入 http://localhost:8080 。
  2. 故障排除：
    • 若端口冲突，请将 8080 修改为其他端口。
    • 确认Docker Desktop已运行，Linux系统可能需要使用 sudo 。

方式二：Docker Compose部署（推荐）

  1. 克隆项目：
git clone https://github.com/zhinianboke/xianyu-auto-reply.git
cd xianyu-auto-reply
  1. 运行部署脚本：
./docker-deploy.sh
  1. 访问系统： 输入 http://localhost:8080 。
  2. 故障排除：参见 DOCKER_FIX.md，检查 docker-compose.yml 端口配置。

方式三：本地部署

  1. 克隆项目：
git clone https://github.com/zhinianboke/xianyu-auto-reply.git
cd xianyu-auto-reply
  1. 安装依赖：
pip install -r requirements.txt

请确保安装了Python 3.11及以上版本。 3. 安装Playwright（商品搜索功能需要）：

playwright install chromium
  1. 启动系统：
python Start.py
  1. 访问系统： 输入 http://localhost:8080 。

配置管理员密码

  • 默认管理员账户：用户名 admin ，密码 admin123 。
  • 修改密码：首次登录后请在用户管理页面更改密码以确保安全。
  • 配置存储于 global_config.yml，可设置WebSocket、API、回复规则等。

功能操作流程

1. 用户注册与登录

  • 操作步骤：
    1. 访问 http://localhost:8080/register.html 。
    2. 填写邮箱并完成验证码验证。
    3. 输入图形验证码完成注册。
    4. 登录 http://localhost:8080/login.html，使用注册的邮箱和密码。
  • 安全特性：系统使用JWT认证，确保数据隔离，防止暴力破解。

2. 添加闲鱼账号

  • 操作步骤：
    1. 登录后进入主界面，点击“添加新账号”。
    2. 输入闲鱼账号ID和Cookie值（可通过扫码登录获取）。
    3. 系统将自动启动账号监控，并显示连接状态。
  • 批量操作：支持同时启动或停止多个账号任务。
  • 注意：定期更新Cookie以避免失效。

3. 配置自动回复

  • 关键词匹配：
    1. 进入“数据管理”页面，添加关键词和回复内容。
    2. 示例：关键词“价格”，回复“商品价格为XX元”。
    3. 支持商品专用关键词及全局通用关键词，优先级为专用 > 通用 > AI回复。
  • AI智能回复：
    1. 在设置页面输入OpenAI API密钥，选择模型（如GPT-3.5）。
    2. 配置提示词，启用AI回复。
    3. 系统会根据上下文生成智能回复，支持动态变量（如用户名）。
  • Excel导入导出：
    1. 下载系统提供的Excel模板。
    2. 填入关键词和回复，上传至“数据管理”页面。
    3. 系统将验证数据格式并自动导入。

4. 设置自动发货

  • 操作步骤：
    1. 进入“发货管理”页面，添加发货规则。
    2. 设置商品关键词及发货内容（文本或卡密文件）。
    3. 配置延时发货时间（0-3600秒）。
    4. 系统将在检测到付款消息后自动匹配规则进行发货。
  • 多规格支持：可自动匹配商品规格，失败时降级到普通卡券。
  • 防重复机制：避免重复发货与确认。
  • 发货统计：可查看发货记录与统计数据。

5. 商品管理

  • 操作步骤：
    1. 系统可自动收集消息中的商品信息。
    2. 通过闲鱼API获取完整商品详情。
    3. 在“商品管理”页面进行编辑或批量管理商品。
  • 多规格支持：管理不同规格的商品信息。
  • 智能去重：避免重复存储商品数据。

6. 商品搜索

  • 操作步骤：
    1. 登录后访问“商品搜索”页面。
    2. 输入关键词与页数，系统将通过Playwright获取真实数据。
    3. 商品按“人想要”数量排序，支持查看详情。
  • 前端分页：灵活显示多页商品数据。

7. 系统监控

  • 实时日志：可在“日志管理”页面查看操作日志。
  • 性能监控：检查系统资源使用率。
  • 健康检查：确保服务正常运作。

注意事项

  • 安全性：请勿将Cookie或密码硬编码，建议使用 .env 文件储存。
  • 合规性：请遵守闲鱼平台规定，避免频繁操作导致账号限制。
  • 日志管理：定期清理 logs/ 目录下的日志文件，以释放空间。
  • 数据备份：系统将自动备份数据至挂载目录，需定期检查。

应用场景

  1. 个人闲鱼卖家：小规模卖家可通过自动回复与发货功能，快速回应买家咨询，提高成交率。
  2. 多账号运营者：管理多个闲鱼账号的用户可统一监控消息和商品，简化流程。
  3. 夜间客服需求：系统支持全天候自动回复，适合夜间无法手动处理的卖家。
  4. 批量商品管理：销售多种商品的卖家可以利用商品管理和自动发货功能，高效处理订单。
  5. 数据分析需求：卖家可通过商品搜索和日志统计功能，分析市场需求和销售情况。

QA

  1. 工具是否免费？：项目为开源，免费用于学习和研究，禁止商业使用。
  2. 支持哪些AI模型？：支持OpenAI的GPT-3.5、GPT-4及通义千问，需配置API密钥。
  3. 如何避免账号被封？：应设置合理的回复间隔，遵循闲鱼规定，定期更新Cookie。
  4. 商品搜索功能需额外配置吗？：需安装Playwright与Chromium，Docker部署已包含。
  5. 如何查看系统日志？：在“日志管理”页面查看实时日志，或检查 logs/ 目录文件。
