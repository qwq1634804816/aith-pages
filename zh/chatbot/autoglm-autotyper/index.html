智谱AI输入法：提升写作效率的智能语音输入与润色工具

autoglm.zhipuai.cn/autotyper/

一款通过大模型技术改变文本输入体验的智能输入法，支持多种功能与场景。

智谱AI输入法（AutoTyper）是智谱AI推出的智能输入工具，旨在通过先进技术改善文本输入体验。这款软件采用GLM-ASR语音识别模型及AutoGLM智能体能力，突破了传统输入法的局限性。它不仅具备高准确率的语音识别功能，支持中英混合及多种方言识别，更重要的是它具有“AI辅助写作”的功能。用户可以通过语音指令生成结构化文本，或对现有文字进行润色、翻译及风格改写（例如将口语转为正式邮件或鲁迅体），它是一款理解上下文并具备推理能力的生产力工具，实现了高效的“你说，我写”办公模式，让内容创作及沟通变得更加顺畅。

功能列表

  • 精准语音转文字：利用GLM-ASR-2512模型，能够快速实时识别语音，准确处理中文与英文混合输入，并支持多种方言。
  • 智能润色与改写：提供多种写作风格可选（如“面向老板”、“面向同事”等），迅速将口语指令转换为合适的书面表达。
  • 多场景文案生成：内置工作汇报、请假条等场景模板，用户只需口述核心需求，AI便会自动生成完整文档。
  • 实时翻译与沟通：支持将语音直接翻译为多种外语，促进跨国交流。
  • 全局悬浮与跨应用支持：以悬浮窗形式在任何可输入文本的软件中直接使用。
  • 长文本处理：能够处理长篇语音输入，适合会议记录及文章创作。

使用帮助

智谱AI输入法旨在隐形高效，安装后作为系统级辅助工具运行。以下是安装及使用指南：

1. 下载与安装

  • 下载：访问官网 https://autoglm.zhipuai.cn/autotyper/，网站将自动识别操作系统，并提供下载链接。
  • 安装（Windows）：双击下载的 .exe 文件，按照指引完成安装，软件会在系统托盘中自动启动。
  • 安装（macOS）：双击 .dmg 文件，将软件图标拖入 Applications 文件夹，首次启动需授予权限。

2. 账号登录

启动软件后，通过手机号或微信扫描二维码进行登录，新用户通常会获得免费积分。

3. 核心功能操作

  • 语音输入（基础模式）：选择输入框，长按快捷键（默认为 F1 或 Option），开始说话，松开后文字将显示。
  • AI润色与改写（进阶模式）：通过选中文字或语音指令生成格式化文本。
  • 切换输入风格：在悬浮窗设置中预设输出风格。

4. 个性化设置

点击设置图标，进行麦克风灵敏度调整及快捷键自定义等。

使用者可先在记事本实践长按说话功能，通常10分钟内即可熟悉高效输入。

应用场景

  1. 职场沟通与汇报：口述大意后，AI能自动生成专业的汇报文本。
  2. 跨国会议与邮件：用户可用中文口述，输出为英文邮件格式，提升沟通效率。
  3. 自媒体内容创作：支持快速记录灵感并生成可发布草稿。
  4. 会议纪要实时整理：实时转录发言内容，方便后续整理。
