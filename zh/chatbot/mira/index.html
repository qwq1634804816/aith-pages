Mira：自动执行公司研究分析的智能体AI库

github.com/DimiMikadze/Mira

Mira是一个智能体AI库，专注于自动化公司研究，提供灵活的数据收集与分析功能。

Mira 是一个针对公司研究的智能体AI库，能够自动执行研究任务。用户只需提供一个公司的官方网站，Mira便会启动由多个专门AI智能体协作构成的系统。这些智能体会分别负责发现并抓取公司页面、分析 LinkedIn 公开资料以及整合谷歌的搜索结果。它们能够自动提取关键信息，验证外部来源，最终生成结构化的公司简介，每项信息都附带来源和可信度分数，以确保信息的透明和可靠。Mira的核心构架独立于开发框架，可以轻松作为 npm 包集成到现有应用中。此外，项目还提供了一个基于 Next.js 的前端示例应用，以便用户更好地理解和使用。

功能列表

  • 多智能体架构：系统设计了多个专门的智能体，分别处理公司信息发现、内网页面抓取以及综合分析，最终输出统一的公司画像。
  • 灵活与可定制：用户可以方便地调整智能体的行为、抓取数据点和设计提示，以适应特定的工作流程或研究需求。
  • 实时进度反馈：在执行研究任务时，系统会发出结构化事件，供用户实时跟踪任务进展。
  • 置信度评分与来源验证：每项提取的信息都标注有可信度评分和其来源，确保研究的透明度。
  • 公司标准匹配：能够根据用户设定的标准评估目标公司，提供匹配得分和详细分析理由。
  • 内置数据收集服务：集成了处理网页抓取、谷歌搜索和 LinkedIn 数据的服务，支持自动处理 Cookie 同意。
  • 智能任务协调：系统可自动协调各个智能体的任务、合并结果并管理数据源。
  • 可组合的核心库：该核心库独立于具体开发框架，方便在任何 Node.js 或 TypeScript 项目中使用。
  • 示例前端界面：项目附带一个基于 Next.js 的示例网站，展示如何使用核心库并提供简单的运行界面。

使用帮助

Mira是一个功能强大的工具，项目还提供完整的前端应用，使得用户能够在本地轻松运行和测试。用户可以通过以下两种方式使用 Mira。

1. 本地运行带前端的完整应用

这种方法适合希望快速体验Mira功能的开发者。

环境要求：

  • Node.js (版本 18 或更高)
  • npm (一般随 Node.js 一并安装)
  • OpenAI API 密钥
  • ScrapingBee API 密钥

安装步骤：

  1. 克隆代码库 使用以下命令将项目代码克隆到本地：

    git clone https://github.com/dimimikadze/mira.git

  2. 进入项目文件夹并安装依赖 进入刚克隆的目录，并通过 npm 安装所需的依赖：

    cd mira
npm install

  3. 配置环境变量 API 密钥等敏感信息需通过环境变量配置。需创建一个 .env.local 文件，位于 packages/mira-frontend/ 目录中。可行以下命令快速创建并编辑：

    # 请在项目根目录（mira/）下执行此命令
touch packages/mira-frontend/.env.local

    使用代码编辑器打开此文件并按格式填入 API 密钥：

    OPENAI_API_KEY=sk-xxxx
SCRAPING_BEE_API_KEY=xxxx

    请确保将 sk-xxxx 和 xxxx 替换为真实密钥。

  4. 运行前端应用 完成上述步骤后，可使用以下命令启动开发服务器：

    npm run dev:mira-frontend

    启动成功后，终端将显示本地网址（通常为 http://localhost:3000）。在浏览器中访问该网址即可进入Mira的操作界面。

2. 作为 NPM 包在你的项目中使用

若想将Mira的自动化研究功能集成到其他应用中，可直接作为 npm 包使用。

安装：

在 Node.js 或 TypeScript 项目中，使用以下命令安装 mira-ai 核心库：

npm install mira-ai

使用方法：

安装后，在代码中导入 researchCompany 函数调用Mira的核心功能。以下是基本使用示例：

import { researchCompany } from "mira-ai";
async function runResearch() {
  // 配置API密钥
  const config = {
    apiKeys: {
      openaiApiKey: process.env.OPENAI_API_KEY,
      scrapingBeeApiKey: process.env.SCRAPING_BEE_API_KEY,
    },
  };  
  // 定义研究参数和回调函数
  const options = {
    // 提供自定义公司标准供AI评估
    companyCriteria: "B2B SaaS领域的公司，且员工人数超过50人",
    // onProgress为接收实时进度更新的回调函数
    onProgress: (event) => {
      console.log("实时进度事件:", event);
    },
  };
  try {
    const result = await researchCompany("https://www.example.com", config, options);
    console.log(result);
  } catch (error) {
    console.error("研究过程中发生错误:", error);
  }
}
// 确保在运行前已设置好环境变量 OPENAI_API_KEY 和 SCRAPING_BEE_API_KEY
runResearch();

在示例中，researchCompany函数接受三个参数：公司网址、包含API密钥的配置对象及可选参数。通过 onProgress 回调，可构建实时用户界面展示研究进度。

应用场景

  1. 销售团队：可利用Mira自动化潜在客户生成，设定理想客户画像，批量研究公司，生成精准客户列表。
  2. 投资人：帮助快速评估初创公司的基本面，聚焦于潜力投资机会。
  3. 招聘专员：建立目标公司清单，更精准寻找候选人，调整招聘策略。
  4. 市场研究员：横向对比行业内多家公司，提高数据一致性与可比性。

常见问题解答

  1. Mira是什么？与普通聊天机器人有何不同？：Mira是智能体AI库，主动协作收集信息，与回答问题的聊天机器人有所不同。
  2. 使用Mira需要哪些API密钥？：需两个API密钥，OPENAI_API_KEY和SCRAPING_BEE_API_KEY，前者用于AI推理，后者支持网页抓取。
  3. 可以自定义Mira收集信息吗？：可以，Mira设计灵活，允许用户定制智能体和抓取数据点。
  4. Mira能否集成到现有CRM中？：可以，通过API调用，轻松将Mira生成的研究报告整合入CRM系统。
