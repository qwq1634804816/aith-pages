Clawd Code：复刻Claude Code泄露版本的Python开源移植代码

github.com/instructkr/clawd-code

Clawd Code 是一个独立且开源的 Python 项目，旨在将泄露的 Claude Code 核心交互与工具调度机制进行复现。

Clawd Code 是一个旨在将泄露的 AI 编程助手 Claude Code 进行 Python 开源移植的独立项目。最初由开发者基于 oh-my-codex (OmX) 框架研发，聚焦于“Harness Engineering”（智能体调度工程），探索 AI 系统如何高效调度外部工具、编排复杂任务及管理超长运行上下文。该工具不仅是代码库的备份或概念验证，而是真正能“完成实际工作”的自动化编程助手。通过本地运行，它可以自主读取文件系统、执行代码、运行测试，并提供多种高级协作模式，让开发者深入理解下一代自动化 AI 开发智能体的工作原理与底层设计。

功能列表

  • 复刻 Claude Code 的终端原生体验：在终端环境中与大语言模型对话，AI 能根据自然语言指令自主浏览目录、读取代码文件、编写和修改代码，并触发本地测试。
  • 并行代码审查（$team 模式）：独特的多线程模式，支持同时启动多个 AI 实例深度审查代码库，确保多方位的代码质量验证和安全审查。
  • 架构级持久化执行（$ralph 模式）：支持持续的执行循环，AI 能从“架构师”的角度逻辑推理、代码生成与多轮验证，确保任务完全符合要求。
  • OmX 底层工作流引擎支持：利用 oh-my-codex 布局流程编排，提供灵活的底层调度逻辑，保证大语言模型在复杂任务中不易丢失上下文。
  • 灵活的外部工具链集成：通过配置环境变量或 Token，让智能体直接呼叫 GitHub、Linear 等第三方工具，实现自动化工作流。
  • 自定义工作区与智能体身份管理：使用 Markdown 文本文件管理智能体的指令和记忆上下文，用户可随时编辑本地文本以改变 AI 的个性、编码规范与工作流习惯。

使用帮助

欢迎使用 Clawd Code。这款工具是基于 Claude Code 泄露版本构建的终端 AI 编程助手，能够自动化处理编码、审查和测试任务。为确保充分发挥工具潜力并实现最佳效率，请详读安装与操作指南。

一、 安装与前置环境准备

1. 系统与环境要求

  • 操作系统：支持 macOS、Linux 和 Windows（推荐使用 WSL2 以获得最佳终端兼容性）。
  • Python 版本：需安装 Python 3.10 或更高版本。
  • 包管理工具：建议使用 pip，为避免依赖冲突，最好配合 virtualenv 或 conda 创建隔离的 Python 虚拟环境。

2. 获取源码与依赖安装
打开命令行终端，执行以下命令将 Clawd Code 项目克隆到本地并安装必要的依赖项：

# 克隆开源仓库到本地
git clone https://github.com/instructkr/clawd-code.git
cd clawd-code
# 创建并激活 Python 虚拟环境（推荐操作）
python3 -m venv venv
source venv/bin/activate  # Windows 用户请使用 venv\Scripts\activate
# 安装项目的核心依赖包
pip install -r requirements.txt

3. 环境变量与 API 密钥配置
Clawd Code 基于大语言模型的智能体系统，需配置模型 API 密钥以赋予其思考和编码能力。项目根目录下提供了基础的环境变量模板文件 env.example。

cp .env.example .env

使用文本编辑器（如 vim、nano 或 VS Code）打开新创建的 env 文件，填入您的 API Key：

# 必填：配置 [Anthropic](https://www.kdjingpai.com/en/claudeanquanfubai/) 的 API 密钥（推荐使用 Claude 3.5 Sonnet）
ANTHROPIC_API_KEY="sk-ant-api03-xxxxxxxxxxxxxxxxxxxx"
# 选填：如需智能体执行 GitHub 自动化提交流程，建议配置 Personal Access [Token](https://www.kdjingpai.com/en/tokenization/)
GITHUB_ACCESS_TOKEN="ghp_xxxxxxxxxxxxxxxxxxxxxxxxxx"

二、 核心功能与基础操作流程

1. 启动并进入智能体交互模式
确保环境变量配置无误且虚拟环境已激活后，通过以下命令启动智能体主程序：

python main.py

启动后，终端进入交互式命令提示符界面。此时 Clawd Code 接管了当前目录的上下文。您可以直接用自然语言发布开发任务。
基础操作示例：
👤 User: “请分析当前目录下的 src/utils.py 文件，找出可能导致内存泄漏的函数，并给出重构建议。”
🤖 Agent: (Clawd Code 开始调度本地文件读取工具 -> 分析代码内容 -> 输出分析报告 -> 询问您是否需要其直接修改该文件)

2. 使用 $team 模式：并行代码审查
在大型 Pull Request 或涉及多个模块的重构时，单线思考的 AI 可能会产生遗漏，此时，可以调用 Clawd Code 的 $team 模式。
操作方式：在终端交互模式下，输入带 $team 前缀的指令：

$team 审查当前 Git 分支中所有的修改，重点检查 SQL 注入漏洞和多线程安全问题。

工作原理：OmX 调度引擎会派出多个独立评估的 AI 实例（如网络安全、运行性能、代码规范），并行读取代码，随后汇总审查意见，显著提高 Code Review 的严谨度与效率。

3. 使用 $ralph 模式：架构级持久验证执行
常见的代码生成工具通常仅“一次性写出代码”，未必保证“这些代码能在整体架构中顺利运作”。$ralph 模式是专为此设计的高级功能，赋予 AI 持久循环执行和多步试错验证的权限。
操作方式：

$ralph 将项目底层的 SQLite 操作迁移至 PostgreSQL，请自行修改代码、编写单元测试并运行验证，直到测试通过。

工作原理：启动后，Clawd Code 会进入“思考 -> 计划 -> 编码 -> 运行测试 -> 捕捉报错 -> 自我修正 -> 再次测试”的全自动闭环。您可观察到进程与状态日志，并随时按 Ctrl+C 手动介入或终止，非常适合处理系统级的重构任务。

三、 进阶配置：定制工作区与外部工具集成

1. 管理智能体记忆与工作区 (.workspace)
初次运行 Clawd Code 时，项目目录下会自动生成类似于 .clawd-workspace/ 的隐藏配置文件夹，存放若干 Markdown 格式的配置文件：

  • identity.md：定义智能体角色和性格。例如，您可以将其改为“你是一个对于代码要求极高的 Linux 内核开发者”。
  • rules.md：设定项目的编码规范，如“本项目所有 Python 函数必须使用 Type Hints，不可用全局变量，必须写 Docstring”。您可通过文本编辑器修改这些本地 Markdown 文件，自定义符合团队习惯的专属 AI 助手。

2. 外部工具调度配置 (Tools & Integrations)
Clawd Code 的强大在于其“工具链”的扩展能力。通过配置特定的 Token，智能体能直接操作第三方工具：

  • 对接 GitHub 流水线：配置文件中的 GITHUB_ACCESS_TOKEN，可直接让终端执行提交和创建 PR。Clawd Code 会自动调动 Git 命令与 GitHub API 完成操作。
  • 调用本地 CLI 工具：若您的系统安装了格式化或静态分析工具（如 black、mypy 或 ruff），可直接命令 AI：“在代码修改完毕后，请格式化所有修改文件”。AI 会如真实程序员般执行相应命令并清理代码。

四、 注意事项与最佳实践

  1. 安全与权限隔离：Clawd Code 具备读取、写入甚至删除本地文件的权限，建议在使用未知来源的自动化任务或涉及核心生产数据时，使用 Docker 或专用沙盒虚拟机以避免误删或覆盖重要文件。
  2. Token 开销与成本监控：频繁使用 $team 和 $ralph 模式将造成大量 API 请求，建议在进行复杂任务前先让 AI 输出简单执行计划，确认逻辑无误后再执行。
  3. 学术研究与二次开发：本项目旨在让开发者透明地了解大模型的工具调度原理，建议仔细阅读底层源码以学习 Clawd Code 如何解析模型输出，并将其转化为本地 Python 函数执行。

应用场景

  1. 本地自动化编程与代码重构：在处理遗留代码库时，开发者可利用 Clawd Code 自动分析复杂的函数依赖关系，并在本地环境直接应用重构补丁，简化操作流程。
  2. 多维度的代码库并行审查：在代码合入主干时，使用 $team 模式对代码库进行快速自动化排查，Clawd Code 从网络安全性、执行性能与代码规范等多视角给出审查意见，提升审查效率。
  3. 智能体架构研究与二次开发：为 AI Agent 开发者提供了一份干净架构的参考源码，帮助学习如何用 Python 构建任务持久化队列，截获并处理模型输出。
  4. 复杂问题的闭环修复 (Bug Fixing)：使用 $ralph 模式，让 Clawd Code 自主分析报错日志、修正业务逻辑并反复运行本地测试，直至无异常。

QA

  1. 该项目与原版 Claude Code 的关系？
    Clawd Code 是基于泄露版 Claude Code 的独立开源 Python 重新实现版本，精准复现其核心的工具调度与终端代理机制。
  2. 为什么要进行 Python 开源移植？
    本工具主要用于教育目的。原版 Claude Code 代码闭源且结构复杂，而此开源版本去除商业部分，为开发者提供了透明学习的材料。
  3. 运行 Clawd Code 需支持什么模型？
    基于 OmX 的调度框架需强逻辑推理及原生工具调用能力的大型语言模型，建议配置 Claude 3.5 Sonnet / Opus 或 OpenAI 的 GPT-4o。
  4. 项目能用于商业开发吗？
    该项目虽开源，但开发者明确标明其主要用于学习。私人集成至商业工作流时，需自行承担潜在的成本和安全责任，建议在沙盒或容器中运行以需保证文件安全。
