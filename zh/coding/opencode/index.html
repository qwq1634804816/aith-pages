OpenCode：在终端环境中运行的AI编程智能体

github.com/sst/opencode

OpenCode是一个专为终端设计的开源AI编程工具，旨在帮助开发者高效完成编程任务。

OpenCode 是一个专为终端环境而构建的开源 AI 编程智能体。它使得开发者能够在命令行界面下生成、修改和调试代码，而无需离开当前的环境。其主要优势在于灵活性和开放性。用户可以选择接入不同的 AI 模型，如 Anthropic、OpenAI 和 Google，甚至是本地的私有模型。这种设计避免了供应商的锁定，同时让用户在模型的价格和性能竞争中获益。

OpenCode采用客户端/服务器架构，允许核心服务在一台计算机上运行，开发者可以通过其他设备（如笔记本电脑或手机）远程连接。对于使用 Neovim 等终端工具的开发者，OpenCode 提供了无缝衔接的交互体验，使 AI 编程能力与熟悉的工作环境结合在一起。

功能列表

  • 终端原生体验：提供完整的终端用户界面（TUI），实现与 AI 的流畅交互。
  • 模型无锁定：支持多种大型语言模型，包括 Anthropic（推荐）、OpenAI、Google 及本地模型。
  • 开放源代码：项目完全开源，采用 MIT 许可证，方便开发者审查、修改和分发。
  • 客户端/服务器架构：允许远程连接并操作 AI 智能体服务。
  • 跨平台安装：支持 macOS、Linux 等主流操作系统，并适配各种包管理器。
  • 社区驱动：项目由社区支持，鼓励代码贡献、错误修复和文档完善。

使用帮助

OpenCode 致力于简化开发者的安装和使用流程，助力快速上手。

安装流程

OpenCode 提供多种安装方式，以适应不同的操作系统和用户偏好。你可以选择最适合你的方法。

1. 快速安装（推荐）

对于大多数 macOS 和 Linux 用户，使用官方提供的一键安装脚本是最便捷的选择。打开终端并运行：

curl -fsSL https://opencode.ai/install | bash

该脚本会自动检测系统环境并将 OpenCode 安装到合适的位置。

2. 使用包管理器安装

如果你倾向于使用包管理器，也可以通过它们来安装 OpenCode。

  • 对于 npm / bun / pnpm / yarn 用户：
npm i -g opencode-ai@latest
  • 对于 macOS 和 Linux 的 Homebrew 用户： 添加软件源后，使用：
brew install sst/tap/opencode
  • 对于 Arch Linux 用户： 使用 paru 或其他 AUR 助手：
paru -S opencode-bin

重要提示

在安装新版本前，请确保卸载所有低于 0.1.x 版本的旧版本，以避免冲突。

自定义安装目录

默认情况下，安装脚本按照以下优先级确定安装目录：

  1. $OPENCODE_INSTALL_DIR：若设置该环境变量，将作为首选安装路径。
  2. $XDG_BIN_DIR：遵循 XDG 基本目录规范。
  3. $HOME/bin：默认的个人二进制目录。
  4. $HOME/.opencode/bin：备用安装路径。

如希望将 OpenCode 安装到特定位置，例如 /usr/local/bin，可以在执行安装脚本前设置环境变量：

OPENCODE_INSTALL_DIR=/usr/local/bin curl -fsSL https://opencode.ai/install | bash

基础使用

安装完成后，在终端中直接输入 opencode 命令即可启动其用户界面（TUI）。

  1. 启动 OpenCode：输入 opencode 启动。
  2. 与 AI 交互：在交互式环境中，可以如同聊天工具直接输入需求，比如：
    • “请帮我写一个 Python 函数，用来计算斐波那契数列。”
    • “分析这段代码的性能瓶颈，并给出优化建议。”
    • “将这个 JSON 文件转换成 CSV 格式。”
  3. 代码操作：AI 生成代码后可进行复制、修改或保存。OpenCode 的 TUI 设计参照了 Neovim 等终端编辑器，因此操作非常高效。

配置说明

OpenCode 的设计不依赖于单一的 AI 模型供应商。用户需在配置文件中指定希望使用的模型，可以参考官方文档。通常需要提供所选 AI 服务商的 API 密钥，并将其配置。这样可灵活切换，确保选择最具性价比的模型。

有关更详细的配置和高级用法，如本地模型设置或远程连接，请访问官方文档。

应用场景

  1. 终端内的快速开发与原型验证： 开发者可直接在终端启动 OpenCode，通过自然语言描述需求，实现高效的开发。
  2. 远程服务器编程与维护：OpenCode 作为终端工具可在远程服务器上运行，支持各种编程和维护任务。
  3. 学习新技术与 API：用户可直接提问来获取代码示例，加速学习过程。
  4. 自动化脚本编写：OpenCode 是系统管理员和 DevOps 工程师的优秀助手，能快速生成各类脚本代码。

QA

  1. OpenCode 和 Claude Code 有什么不同？
    • 开源性：OpenCode 是完全开源的，而 Claude Code 是闭源的。
    • 模型灵活性：OpenCode 不锁定特定供应商，支持多种模型。
    • 交互界面：提供终端用户界面，确保命令行交互流畅。
    • 架构：客户端/服务器架构提升了使用的灵活性。
  2. OpenCode 支持哪些 AI 模型？
    • 支持多种主流语言模型服务，包括 Anthropic、OpenAI 和 Google，同时支持本地开源模型。
  3. 我该如何为 OpenCode 项目做贡献？
    • 欢迎社区贡献，包括代码修复、性能提升和文档完善等。重大更改需先与核心团队讨论，以确保顺利合并。通常建议在提交请求前，了解项目的贡献历史，以提高接受的概率。
