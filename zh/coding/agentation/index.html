Agentation：为AI编程助手生成前端UI上下文的标注工具

agentation.dev/

一款专为前端开发者设计的轻量级辅助工具，用于解决与AI编程助手沟通UI问题时的上下文缺失。

Agentation 是一款面向前端开发者的轻量级工具，旨在解决与AI编程助手（如 Claude Code、Cursor、Windsurf）互动时的“上下文缺失”问题。在传统的开发过程中，当开发者在网页上发现样式错误或交互故障时，很难用自然语言阐明元素在代码中的具体位置。Agentation 遵循“所见即所得”的原则，允许用户直接点击网页元素进行标注，自动捕获该组件的类名、选择器和层级位置，并将这些技术细节与用户反馈合成结构化的 Markdown 格式。用户只需将信息复制给 AI，便可以利用这些精确的定位信息快速索引到源文件并进行修复。该工具基于 React 构建，零额外依赖，完全独立于特定 AI 模型，任何能够读取文本的 AI Agent 均可使用。

功能列表

  • 可视化元素标注：通过鼠标悬停和点击，直接在运行中的网页上选择任何 DOM 元素，比如按钮、卡片、文本段落。
  • 自动提取技术参数：选中元素后，工具会自动捕获该元素的 CSS 类名、ID、层级路径等关键定位信息。
  • 结构化反馈生成：支持在选定元素上添加自定义文字说明，并一键生成包含技术上下文的 Markdown 文本。
  • 动画暂停调试：提供“暂停动画”功能，方便捕捉和标注动态效果或特定帧的 UI 问题。
  • 文本精准定位：支持直接选择网页中的文本段落进行纠错，便于 AI 快速定位文案所在的组件位置。
  • 跨平台兼容：生成的输出格式为标准 Markdown，完美支持 Claude Code、Cursor、Windsurf 及任何支持上下文输入的 LLM 编程工具。

使用帮助

Agentation 的核心设计理念是“轻量化”和“无缝集成”，无需复杂的后台配置，以 React 组件形式集成在开发环境中。以下为详细操作流程：

1. 启动与激活

Agentation 主要面向桌面端浏览器。在集成了 Agentation 的项目中，你的网页右下角将出现一个工具图标。

  • 激活工具：点击右下角的 Agentation 图标，或使用配置好的快捷键激活标注模式。此时，当你移动鼠标时，页面上的各个 HTML 元素会被高亮显示。

2. 标注目标元素

当你在网页预览中发现需要修改的部分，例如按钮颜色不当或文字排版错误：

  • 选择元素：将鼠标悬停在目标元素上，点击左键即可锁定该元素。
  • 添加反馈：点击后弹出输入框，输入对该元素的修改意见，如：“按钮的圆角应为 8px”或“此卡片点击无反应”。
  • 多点标注：你可以同时点击多个位置，收集多个修改需求，例如同时指出导航栏的高度和页脚的链接错误。

3. 处理动态内容

对于包含复杂动画或过渡效果的网页，捕捉特定状态可能很困难：

  • 暂停动画：在 Agentation 的工具栏内点击“暂停”图标，强制停止页面上的 CSS 动画，确保页面停留在当前帧。
  • 精准标注：在静止状态下，从容地选择平时一闪而过的动态元素进行标注。

4. 生成并导出上下文

完成所有问题的标注后，需将信息传递给 AI：

  • 生成报告：点击工具栏上的“Copy”或“Export”按钮。Agentation 合并选定元素路径和文字说明生成清晰的 Markdown 文本。
  • 内容预览：生成的文本除了自然语言描述，还包含机器可读的代码定位符，帮助 AI 精确找到文件。

5. 驱动 AI 修复代码

最后一步是与 AI 编程助手对接：

  • 粘贴指令：在 AI 工具（如 Cursor 的 Chat 窗口，或 Claude Code 的终端界面）中粘贴刚才复制的文本。
  • 执行修复：AI 接收到信息后，将通过类名和选择器在代码库中进行全局搜索，迅速定位到对应的组件或 CSS 文件，并根据反馈生成修复代码。

应用场景

  1. UI 样式微调：前端开发中常需调整组件的 Padding、Margin 或颜色。使用 Agentation，开发者只需点击组件并备注“Padding 增加到 20px”，AI 即能定位到样式文件进行修改。
  2. 复杂组件的 Bug 修复：在极深的 React 组件树中，手动查找源文件耗时。Agentation 可生成精确的 DOM 路径，帮助 AI 找到组件具体位置。
  3. 文案内容的批量校对：网页中多处拼写错误时，非技术人员可通过该工具直接选中错误文本并输入正确文案，生成的反馈直接交给 AI 替换，避免了口头沟通的歧义。

QA

  1. Q: Agentation 需要后端服务支持吗？
    A: 不需要。它是纯前端工具，作为 React 组件引入项目中，零后端依赖，所有数据处理在浏览器完成。
  2. Q: 它只支持 React 项目吗？
    A: 目前文档主要展示 React 环境，但核心逻辑通用，作为 npm 包引入时，主要适配 React 生态。
  3. Q: 为什么生成的反馈能让 AI 更好工作？
    A: LLM 不能看见你的屏幕，模糊提示“修复右上角的按钮”不够具体。Agentation 提供的精确代码特征如 .header-right .login-btn，使 AI 能直接检索代码，消除猜测。
  4. Q: 这个工具收费吗？
    A: 目前工具以开源或免费形式存在，目的是优化 AI 编程辅助体验。
