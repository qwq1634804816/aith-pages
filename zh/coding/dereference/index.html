Dereference：并行运行多个AI模型的开发工具

www.dereference.dev/

Dereference是为开发者量身打造的IDE，支持同时管理多种AI会话，具备高效的功能特性。

Dereference 是一款为开发者设计的集成开发环境（IDE）， memungkinkan开发者在多个大语言模型的AI会话间并行运作。工具的主要特点是支持同时处理，用户能够迅速切换至 Claude、GPT-4 和 Gemini 等模型，而且每个对话会话都能维护独立的上下文。它还借鉴了Git的分支和合并机制，允许用户从对话的任意位置创建分支，去探索不同的解决方案，最终将最佳答案合并回来。该工具采纳了Rust语言开发，确保卓越的性能，并特别注意保护隐私，所有对话数据和API密钥均存储在本地，不会上传至服务器。

功能列表

  • 并行AI会话: 支持同时与多个AI模型（如Claude、GPT-4、Gemini）进行对话，并可即时切换。
  • 分支与合并: 可借鉴Git的操作，从任何节点创建分支以探索多种方案，再将满意的结果合并回主分支。
  • 多会话编排: 同时管理多个AI会话，每个会话保持独立上下文，便于比较不同模型的输出。
  • 原子化分支: 类似代码的处理方式对会话进行分支和合并，不会丢失重要上下文。
  • 原生应用性能: 使用Rust构建，响应速度快，内存占用低，避免了Electron等框架的性能损耗。
  • 隐私优先: 用户的对话内容与API密钥存储在本地的钥匙串中，确保不上传至云端。
  • 命令行工具集成: 当前原生支持与Claude Code CLI工具集成，未来将支持更多语言模型的CLI工具。
  • 智能上下文管理: 自动管理每个会话的上下文窗口，智能截断技术确保重要信息不会丢失。

使用帮助

Dereference 是一款旨在提升开发效率的工具，其使用流程简洁明了。用户可以直接从官网下载适用的版本，免去复杂的配置。

下载与启动

  1. 访问官方网站 https://www.dereference.dev/。
  2. 点击页面上的“Download”按钮，选择适合您操作系统的版本（如macOS, Windows, 或 Linux）。
  3. 下载后，解压文件并运行应用程序，无需安装，开箱即用。

核心功能操作

1. 创建和管理并行AI会话 一旦启动应用，用户会看到简洁的界面。

  • 添加新会话: 用于轻松添加新的AI对话标签页，可以为不同任务创建不同会话。例如，一个用于代码生成，另一个用于代码调试。
  • 切换模型: 在每个会话中，可便捷地选择使用哪一AI模型（如Claude、GPT-4或Gemini），快速切换以利用不同模型的特点。

2. 使用分支与合并功能 这是Dereference最具特色的功能之一，受到Git版本控制思想的启发。

  • 创建分支: 如果对某个回答不完全满意，点击“创建分支”即能在对话节点上进行新探索。
  • 探索不同方案: 新分支继承原有对话历史，可自由提问而不扰乱原始上下文，支持并行探索多种解决方案。
  • 合并分支: 满意结果后，可以将该分支内容合并回主对话流，适用于需要反复迭代的任务。

3. 配置API密钥 为使用不同AI模型，需提供相应API密钥。

  • 本地存储: Dereference重视用户隐私，所有API密钥安全存储在本地设备的钥匙串中。
  • 添加密钥: 在设置菜单中找到API密钥管理选项，输入Claude、OpenAI或Google Gemini的API密钥。

4. 智能上下文管理 Dereference自动管理每个会话的上下文，确保不超过模型限制的同时保留重要信息。使用智能截断方法，保证关键信息得到保留，确保AI能够理解任务背景。

应用场景

  1. 复杂代码逻辑开发：在需要实现复杂算法时，能同时向GPT-4、Claude和Gemini提问，便于找到最佳方案。
  2. 代码调试与错误修复：提供系统性探索修复路径，不轻易混淆上下文。
  3. 技术研究与学习：可以记录核心概念，并针对知识点创建分支进行深入探索。
  4. 多语言项目开发：为不同编程语言创建独立AI会话，方便在多语言环境中高效工作。

QA

  2. 我的代码和API密钥安全吗？ 非常安全，所有数据都存储在本地，API密钥加密存储于钥匙串中。
