ChatGPT Codex：自动执行软件工程任务的智能体

chatgpt.com/codex

探索Codex如何在云端执行软件工程任务。

Codex 是一款基于 codex-1 模型的云端软件工程智能体，已整合在 ChatGPT 中。它不仅是一个简单的代码生成工具，更是能够独立执行复杂编程任务的代理程序。Codex 在一个安全的云端沙盒中操作，能够预先加载用户的代码库。它可以根据自然语言指令，完成新功能开发、程序错误修复以及代码库相关问题的回答。在执行任务时，Codex 可以读写文件，运行测试、代码格式化工具，并在确认任务完成后返回结果。它会提交代码变更，并提供详细的操作记录，便于用户审核。

功能列表

  • 执行完整工程任务：根据用户指令，在独立的云端环境中执行具体的软件工程任务，比如修复错误或实现新功能。
  • 代码库交互：可在预加载用户代码库的沙盒环境中直接读取、编辑和写入文件。
  • 执行终端命令：能够在隔离环境中运行指令，例如执行测试工具 (test runners)、代码格式检查器 (linters) 以及类型检查器 (type checkers)。
  • 自动化测试与修复：具备自主运行测试以验证修改的能力，如果测试失败，将尝试多次修改直到通过测试。
  • 生成变更和审查请求：完成任务后，通过 git commit 提交变更，并生成包含操作证据的 GitHub 变更请求（Pull Request）供人工审核。
  • 遵循项目规范：可以通过读取项目中的 AGENTS.md 文件了解并遵循特定的开发环境配置、测试指令及工作流程。
  • 代码库问答：用户可以询问当前加载的代码库，以获取相关信息和解释。
  • 安全隔离执行：所有任务在一个与外界网络隔离的安全容器中执行，以确保用户代码的安全。

使用帮助

作为强大的软件工程智能体，Codex 的使用方法超越了传统的代码生成。它模拟了一位远程协作的软件工程师，你需要将任务委派给它，并在完成后进行审查。

核心使用流程

  1. 启动 Codex:

    • 在 ChatGPT 的侧边栏中选择 Codex。
    • 按照提示，将 Codex 连接到你的 GitHub 代码库，此时 Codex 会在一个独立的云端沙盒环境中操作。

  2. 分配任务:

    • 执行编程任务：若需要其修改代码，比如修复一个bug或添加功能，输入清晰的指令，然后点击 Code 按钮。例：“请修复 astropy/astropy 库中 Modeling 的 separability_matrix 计算问题。”
    • 询问代码库问题：若想了解代码库的某些方面，输入问题并点击 Ask 按钮。例如：“请解释一下用户认证处理逻辑在哪里。”

  3. 监控与等待:

    • 任务开始后，Codex将在背景的沙盒环境中自动工作，复杂任务可能需 1 到 30 分钟。
    • 实时监控执行进度，了解正在执行的操作，例如读取文件、运行命令等。

  4. 审查结果:

    • 任务完成后，Codex 会提交在沙盒环境中的代码变更。
    • 提供详细报告，其中包括可验证的操作证据，如执行的终端命令日志和测试输出结果，便于用户追溯每一步和确保操作透明度。
    • 用户可仔细审查修改后的代码、commit 信息及测试结果。

  5. 后续操作:

    • 请求修改：如有不符合预期的结果，可以提出进一步修改要求。
    • 创建变更请求：满意后，可一键让 Codex 创建 GitHub 变更请求（Pull Request），便于团队审核代码。
    • 整合到本地：选择将变更直接整合到本地开发环境。

使用 AGENTS.md 文件引导 Codex

为了使 Codex 更高效、准确地完成任务，可在代码库中创建 AGENTS.md 文件，类似于 README.md 的说明书。

  • 作用：可在文件中指示 Codex 如何浏览代码库、执行哪些测试指令、项目遵循的编码规范和标准作业流程。
  • 示例内容: 
    # AGENTS.md
## 如何运行测试
要运行完整的测试套件，请在项目根目录执行以下命令：
`pytest`
## 编码规范
本项目遵循 PEP 8 编码规范。在提交代码前请确保运行 `flake8 .`无错误。
## 关键模块说明
- `src/core/auth.py`：用户认证和会话管理。
- `src/api/v1/`：V1版本所有API端点定义。

就像一个人类开发者一样，当开发环境配置良好、测试框架稳定、文档说明清晰时，Codex 的表现会更佳。

应用场景

  1. 自动化日常维护任务：对重复性且明确的任务，如代码重构或增加单元测试，可委托 Codex 处理，从而使开发者能专注于更具创造性的工作。
  2. 快速修复已知错误：收到明确的错误报告时，开发者可以将其直接交给 Codex，后者会自动修复问题并验证。
  3. 搭建新功能框架：在开发新功能时，可让 Codex 建立基础框架，如 API 端点等。
  4. 提升代码库质量：可以指派 Codex 执行提高代码质量的任务，例如格式化不规范代码。

FAQ

  1. 将我的私有代码库连接到 Codex 是否安全？：是的，Codex 在完全 isolated 的安全云端沙盒容器中执行任务。在此期间无法访问外部网站或服务。
  2. AGENTS.md 文件是必需的吗？：不是必需的，但能显著提升 Codex 表现，提供项目指南，帮助其更快融入。
  3. Codex 和在 ChatGPT 中请求代码的区别?：前者在真实开发环境中运行，后者仅生成文本形式代码，操作方式不同。
  4. Codex 执行任务时间?：一般需要 1 到 30 分钟，因涉及多个步骤，与真实开发者工作流程模拟相似。
