Airbook：一个用于分析和运营的GTM数据平台

www.airbook.io/

Airbook 是一个专为分析和运营打造的GTM数据平台，提供AI驱动的统一工作空间。

Airbook 是一个专为数据分析与运营打造的GTM（Go-to-Market）数据平台，提供一个由AI支持的统一工作空间，以连接和整合分散在企业中的各种数据和业务团队。通过此平台，团队能够快速连接CRM、产品分析、市场营销、财务等不同系统的数据。用户可以利用自然语言或SQL简单地进行复杂数据查询和分析，从而迅速识别促进收入增长的关键因素。Airbook 将商业智能、数据仪表盘和工作流集成在一个类似文档的协作环境中，使得数据分析不仅限于数据专家，业务团队也可自助服务，从而提高决策效率，促进业务增长。

功能列表

  • AI助手：用户能够通过自然语言（如“上个月哪些营销活动带来的付费用户最多？”）向AI助手提问，该助手会直接分析连接的数据源并提供答案。
  • 数据连接：无需依赖工程团队，用户可以直接连接多种业务应用、数据库和数据仓库，如Salesforce、HubSpot、Snowflake、Zendesk、Stripe等。
  • 统一工作空间：提供类似Notion的协作界面，团队成员可以在一个平台上完成从数据连接、分析到执行的全流程。
  • 无代码与SQL分析：平台支持无代码的操作与专业SQL查询，以满足不同技术背景用户的需求。
  • BI仪表盘：用户可以轻松创建图表和交互式仪表盘，以可视化分析结果，方便团队共享理解。
  • 数据激活：通过分析得出的结论可直接转化为行动，如创建目标受众列表，并将其同步到营销工具以实施个性化营销。
  • 权限管理：提供细致的角色与权限控制，确保数据在安全环境中被授权的人员使用。

使用帮助

Airbook 是个在线SaaS（软件即服务）平台，无需在本地安装复杂的程序。用户通过官网注册账号即可使用，整个操作流程十分直观，有助于提高数据分析效率和协作。

步骤一：注册并登录

访问 Airbook 官方网站 https://www.airbook.io/，点击“Get started free”按钮，按照提示输入邮箱和基本信息创建账户。注册完成后即可登录进入个人工作空间。

步骤二：连接数据源

这是使用 Airbook 的关键步骤，因为平台的价值在于打破数据孤岛，将各业务系统中的数据连接进来。

  1. 进入工作空间后，找到“Connect”或“Data Connections”的选项。
  2. 屏幕上会显示包含多个应用图标的列表，如Salesforce、HubSpot、Snowflake等。
  3. 选择想要连接的应用程序，若要分析销售数据，请点击Salesforce图标。
  4. 点击后，系统会弹出授权窗口，输入该应用的登录凭证并授权 Airbook 访问数据。此过程安全加密，并符合SOC2安全标准。
  5. 授权成功后，Airbook将自动同步相关数据，用户可以通过此流程连接多个不同数据源，整合公司的销售、市场、产品、财务信息。

步骤三：使用AI助手进行探索式分析

这是 Airbook 的独特功能之一，特别适合不熟悉SQL的业务人员。

  1. 在工作区找到“AI Assistant”的输入框。
  2. 用简单中文或英文输入关心的问题，比如：
    • “过去30天，哪些销售代表成交的客户拥有最高的产品使用率？”
    • “对比一下来自谷歌广告和社交媒体的线索，哪个渠道的转化率更高？”
    • “找出上个季度所有提交了支持工单并在之后流失的客户。”
  3. AI助手会理解问题，自动查询已连接的数据源，以图表或文字形式提供答案，并可追问以获取更多细节。

步骤四：创建分析笔记与仪表盘

针对更复杂的分析需求，用户可利用 Airbook 的笔记本功能整理分析过程并制作仪表盘。

  1. 创建笔记本：Airbook 的工作界面类似文档，用户可在页面中添加文字说明、数据查询、图表和表格。
  2. 查询数据：
    • 无代码查询：通过点击和拖拽选择数据表、字段并设置筛选条件。
    • SQL查询：若熟悉SQL，可直接使用SQL编辑器编写查询语句。
  3. 数据可视化：查询结果后，可将其轻松转化为折线图、柱状图、饼图等，用户可以自定义各项图表特色。
  4. 构建仪表盘：将多个图表组合成仪表盘，团队可实时监控KPIs，仪表盘数据实时更新，无需手动刷新。

步骤五：分享与协作

Airbook 重视团队合作，用户可分享分析笔记或仪表盘给团队成员，并设置权限（如只读或可编辑），团队可在页面上评论和讨论，确保一致的信息基础进行决策。

步骤六：激活数据，驱动业务

分析的最终目的是采取行动。Airbook不仅是分析工具，还能将分析结果转化为实际业务。比如假设分析得出一批“高意向但未购买”的用户，用户可在 Airbook 中创建“受众”，并将其推送到营销工具及时展开精准营销。

应用场景

  1. 收入运营（RevOps）：将Salesforce、HubSpot、Stripe等应用中的数据整合，建立客户全生命周期的真实数据源，有助于进行销售渠道审查及准确收入预测。
  2. 市场营销（GTM Teams）：实时监测营销活动对销售和收入的实际影响，关联系统花费与客户行为，以快速识别潜在客户与流失风险并采取行动。
  3. 数据团队：为业务团队提供自助服务的数据分析环境，数据团队则可专注于更高价值的数据治理和策略工作。

QA

  1. Airbook是什么？ Airbook 是整合AI助手的GTM数据平台，统一整合市场、销售、客户和产品数据，提供便捷的分析和决策支持。
  2. 使用 Airbook 需要懂编程或SQL吗？ 无需掌握。Airbook 设计兼顾技术背景，业务人员可通过AI助手以自然语言提问，亦可使用无代码工具或SQL进行深度分析。
  3. Airbook可以连接哪些类型的数据源？ 支持连接广泛的SaaS应用、数据库和数据仓库，如Salesforce, HubSpot, Zendesk, Stripe, Snowflake等。
  4. Airbook 如何保证我的数据安全？ 平台在数据传输和存储中采取加密措施，并已通过SOC2 Type 2认证，确保高标准的安全性及有效权限管理。
