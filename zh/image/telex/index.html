Telex：WordPress官方出品一键生成现代 WordPress 主题

telex.automattic.ai/

Telex是一款由Automattic开发的实验性AI工具，旨在帮助开发者和用户快速生成自定义的WordPress区块。

Telex 是由 WordPress 母公司 Automattic 开发的一款实验性 AI 编程工具，主要用于协助开发者和建站用户创建自定义的 Gutenberg（古腾堡）区块。用户只需通过日常的自然语言提示词，描述所需的区块结构、样式和交互，Telex 能在短短数十秒内自动生成可运行的 WordPress 区块组件。

该工具深度整合了基于 WebAssembly 的 WordPress Playground 无服务器沙盒环境，生成的代码无需本地开发环境即可在浏览器中进行前端效果预览和编辑器后台测试。Telex 还提供对话式迭代功能，用户可以与 AI 助手进行多次代码微调，生成的最终区块可一键打包导出为标准的 .zip 格式插件文件，便于无缝安装到自托管的 WordPress 网站。

功能列表

  • 自然语言代码生成：支持使用普通文本提示词描述组件的逻辑和外观，AI 可以将其转换为原生的 WordPress Gutenberg 区块代码。
  • 内置 Playground 沙盒预览：无缝集成 WordPress Playground，用户可以实时查看区块的渲染效果及后台参数设置。
  • 对话式持续迭代：用户可以通过侧边栏的 AI 助手对初版区块发出具体修改指令，AI 会理解并更新代码。
  • 一键打包导出插件：支持将完成的区块连同依赖代码压缩为标准 WordPress 插件 ZIP 包。
  • 原生兼容性架构：生成的代码遵循官方区块编辑器的开发规范，确保在各类主题下的兼容性。
  • 代码可视化与审查：允许开发者查看 AI 编写的底层源代码，确保逻辑透明。
  • 视觉参考图解析（逐步开放）：支持用户上传界面截图或线框图，帮助更精准地还原设计。

使用帮助

欢迎使用 Telex！这款由 Automattic 打造的 AI 编程平台能够将您的文本构想直接转化为功能完备的 WordPress 原生区块。为了你能够充分发挥该平台的生产力，以下为您准备了详尽的操作指南。

特别提示：由于 Telex 目前处于实验阶段，为确保完整的代码生成和渲染体验，当前强制要求在桌面端浏览器中使用，移动设备无法打开主工作区。

一、 账号注册与工作区访问

  1. 访问平台：打开推荐的桌面浏览器（如 Google Chrome 或 Microsoft Edge），访问官方网址 https://telex.automattic.ai/。
  2. 账号登录授权：在首页点击“Sign In”登录按钮。Telex 主要使用 WordPress.com 账号体系进行单点登录（SSO）。已有账号可直接授权，若无账号，请免费注册。
  3. 进入控制台：登录后，会看到一个简洁的提示词对话窗口，即为代码生成的起点。

二、 核心操作流程：从提示词到可用插件

步骤 1：撰写高质量的提示词（Prompt）

代码生成的准确性依赖于您输入的细节描述。建议按照“功能定义 + 后台配置 + 视觉样式 + 交互效果”来构建提示词。

  • 需求示例：作一个“团队成员介绍”区块。
  • 推荐提示词：“请生成一个‘团队成员展示’的 Gutenberg 区块。支持每行三位成员的展示。后台配置：允许上传头像、填写姓名、职位与简介。视觉样式：极简风格，头像为正圆形，带有灰色阴影。交互效果：鼠标悬停时，卡片上升 5px 并显示 LinkedIn 和 Twitter 图标。”
  • 提交：确认描述后，按回车键或点击发送图标启动生成。

步骤 2：代码生成与沙盒验证

  • 可视化生成：指令发出后，系统会显示代码生成进度，通常需 30 秒至 1 分钟。
  • WordPress Playground 加载：代码完成后，Telex 会启动无服务器的 WordPress 沙盒，用户可直接测试。
  • 双视角切换：
    • 编辑器视图（Editor）：模拟 WordPress 编辑界面，用户可以测试生成的区块与属性面板。
    • 前端视图（Frontend）：查看区块在网页上的视觉效果及动画。

步骤 3：与 AI 助手对话进行迭代

  • 呼出助手（Assistant）：在右侧面板点击“Assistant”，进入对话模式。
  • 发送修改指令：用简单的语言指出需要修改的内容。
  • 自动更新：AI 会在原有代码基础上，针对要求重新编辑相关部分，完成后沙盒会刷新。

步骤 4：打包导出与部署

一旦区块调试完成，便可将其移植到实际网站。

  1. 导出 ZIP 包：点击“Download”或“Export”按钮，系统会将所有依赖文件压缩为 ZIP 包。
  2. 上传至个人网站：登录 WordPress 网站后台。
  3. 安装启用：在菜单中选择 插件 -> 安装插件 -> 上传插件，安装下载的 ZIP 文件。
  4. 实际调用：在区块编辑器中搜索并添加区块。

三、 进阶使用技巧与防坑指南

  • 代码审查模式：开发人员可查看底层源码并指导 AI 修复复杂问题。
  • 模块化原则：建议将大型项目拆成多个独立功能区块，提升成功率和代码质量。
  • 应对生成失败：如出现渲染失败，点击重新生成或简化提示词。

应用场景

  1. 快速原型设计与演示：网页设计师和产品经理可直接用 Telex 显示交互效果。
  2. 定制化营销活动组件开发：电商团队可快速生成特定视觉风格的区块，节省时间和成本。
  3. 辅助 WordPress 开发者提升效率：Telex 可作为代码副驾驶，帮助开发者聚焦核心逻辑。
  4. 无代码建站者的功能拓展：用户可通过自然语言定制专属组件，打破功能局限。

QA

  1. Telex 是收费工具吗？ 答：目前 Telex 完全免费，未来可能推出收费计划。
  2. 生成的区块可直接安装吗？ 答：只要是支持安装插件的自托管 WordPress 网站，就能直接使用 Telex 导出的 ZIP 文件。
  3. Telex 可以生成完整的 WordPress 主题吗？ 答：不可以，Telex 专注于生成 Gutenberg 区块。
  4. 为何无法在手机上打开 Telex？ 答：需使用桌面浏览器以确保系统运行稳定。
  5. 如何修复生成的区块中的 Bug？ 答：打开 AI 助手描述问题，AI 将自动修正代码并展示修改结果。
