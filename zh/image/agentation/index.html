Agentation：为AI编程助手生成前端UI上下文的标注工具

agentation.dev/

Agentation 是一款轻量级的前端开发辅助工具，消除人与AI编程助手之间的沟通障碍。

Agentation 是专门为前端开发者打造的轻便辅助工具，其目的是解决与 AI 编程助手（如 Claude、Cursor、Windsurf）之间在 UI 沟通中所遇到的“上下文缺失”问题。在传统开发流程中，当开发者在网页中发现样式问题或交互缺陷时，往往难以用自然语言准确描述该元素在代码中的位置。Agentation 遵循“所见即所得”的原则，允许用户直接点击网页上的元素进行标注，自动抓取该组件的类名、选择器和层级位置，并将这些技术细节与用户意见结合生成结构化的 Markdown 信息。用户只需将这些信息传递给 AI，后者即可根据这些精准的定位信息在代码库中迅速查找并修复相关问题。该工具基于 React 开发，零额外依赖，并且完全独立于特定 AI 模型，任何能够处理文本的 AI Agent 均可应用。

功能列表

  • 可视化元素标注：通过鼠标悬停与点击，直接在网页上选取 DOM 元素（如按钮、卡片、文本段落）。
  • 自动提取技术参数：选中元素后，工具自动捕获 CSS 类名、ID、层级路径等定位信息。
  • 结构化反馈生成：在选定元素上添加自定义文字说明并一键生成包含技术上下文的 Markdown 文本。
  • 动画暂停调试：提供“暂停动画”功能，便于捕捉和标注动态效果或特定帧的 UI 问题。
  • 文本精准定位：支持直接选中网页中具体文本段落进行纠错，方便 AI 快速找到文案位置。
  • 跨平台兼容：生成的输出符合标准 Markdown 格式，兼容 Claude Code、Cursor、Windsurf 等所有支持上下文输入的 LLM 编程工具。

使用帮助

Agentation 的关键设计理念是“简约”和“无缝集成”，无需复杂后台配置，以 React 组件的形式集成到开发环境中。以下为详细操作流程与使用指南：

1. 启动与激活

Agentation 现仅支持桌面端浏览器。在已集成 Agentation 的项目中，网页右下角会显示一个工具图标。

  • 激活工具：点击右下角的 Agentation 图标或使用快捷键（如有配置）来激活标注模式。此时，当鼠标移动时，页面中的 HTML 元素将被高亮，表明可选状态。

2. 标注目标元素

在网页中发现需要修改的地方时：

  • 选择元素：将鼠标悬停于目标元素上并点击左键以“锁定”该元素。
  • 添加反馈：点击后会弹出输入框，在此处输入对该元素的修改意见。
  • 多点标注：可连续点击多个不同位置，集中收集修改需求。

3. 处理动态内容

对于包含复杂动画或过渡效果的页面，捕捉特定状态可能较困难。

  • 暂停动画：在 Agentation 工具栏中点击“暂停”图标，强制停止页面的 CSS 动画和 JS 渲染循环。
  • 精准标注：在页面静止时，选中之前一闪而过的动态元素进行标注。

4. 生成并导出上下文

完成所有标注后，将信息传递给 AI：

  • 生成报告：点击工具栏上的“Copy”或“Export”按钮，Agentation 将选中的元素路径及输入的说明整合成清晰的 Markdown 文本。
  • 内容预览：生成的文本不仅包含自然语言描述，还包括机器可读的代码定位符，确保 AI 能准确定位文件。

5. 驱动 AI 修复代码

最后一步，连接你的 AI 编程助手：

  • 粘贴指令：打开正在使用的 AI 工具，粘贴刚才生成的文本。
  • 执行修复：AI 接收到信息后，能够直接通过类名和选择器快速查找到对应文件，生成修复代码。

应用场景

  1. UI 样式微调：前端开发常需调整组件的Padding、Margin或颜色，通过Agentation，开发者可在浏览器中直接点击组件并备注“Padding增加到20px”。
  2. 复杂组件的 Bug 修复：在深层嵌套的 React 组件中手动查找源文件耗时，Agentation 能生成精准的 DOM 路径帮助 AI 快速定位。
  3. 文案内容的批量校对：对于网页中的多处拼写错误，非技术人员可直接选中错误文本并输入正确内容，生成反馈供 AI 替换。

QA

  1. Q: Agentation 需要后端服务支持吗？
    A: 不需要，工具作为 React 组件引入项目，所有数据处理在浏览器本地完成。
  2. Q: 它只支持 React 项目吗？
    A: 目前主要展示了 React 环境的使用，核心逻辑是通用的，但作为 npm 包适配主要是 React 生态。
  3. Q: 为什么生成的反馈能让 AI 工作得更好？
    A: 大模型虽聪明，但不能看到屏幕，传统提示词较模糊，Agentation 提供的精确代码特征让 AI 能更高效地检索代码库。
  4. Q: 这个工具收费吗？
    A: 目前以开源或免费工具形式存在，目的在于优化 AI 辅助编程的工作流体验。
