ChatGPT Codex：An Intelligent Agent for Automating Software Engineering Tasks

chatgpt.com/codex

Explore how Codex executes software engineering tasks in the cloud.

Codex is a cloud-based software engineering agent built on the codex-1 model, integrated within ChatGPT. It is not just a simple code generation tool but an agent that can independently execute complex programming tasks. Codex operates in a secure cloud sandbox, capable of preloading the user’s code repository. It can develop new features, fix program errors, and answer questions related to the codebase based on natural language instructions. When executing tasks, Codex can read and write files, run tests, use code formatting tools, and return results after confirming task completion. It submits code changes and provides detailed operation records for user review.

Function List

  • Execute complete engineering tasks: Execute specific software engineering tasks in an isolated cloud environment based on user instructions, such as fixing bugs or implementing new features.
  • Code repository interaction: Directly read, edit, and write files in a sandbox environment with the user’s preloaded code repository.
  • Execute terminal commands: Able to run commands in an isolated environment, such as running testing tools (test runners), code format checkers (linters), and type checkers (type checkers).
  • Automated testing and repair: Has the ability to run tests autonomously to validate modifications, and if tests fail, will try multiple modifications until they pass.
  • Generate change and review requests: After completing tasks, submit changes via git commit and generate a GitHub pull request (PR) containing operational evidence for manual review.
  • Follow project specifications: Can learn about and adhere to specific development environment configurations, testing instructions, and workflows by reading the AGENTS.md file in the project.
  • Code repository Q&A: Users can ask questions about the currently loaded code repository to obtain relevant information and explanations.
  • Secure isolated execution: All tasks are executed within a secure container isolated from the external network to ensure the safety of user code.

Usage Help

As a powerful software engineering agent, Codex’s usage goes beyond traditional code generation. It simulates a remotely collaborating software engineer, and you need to delegate tasks to it and review upon completion.

Core Usage Process

  1. Start Codex:

    • In the sidebar of ChatGPT, select Codex.
    • Follow the prompts to connect Codex to your GitHub code repository, at which point Codex will operate in an isolated cloud sandbox environment.

  2. Assign Tasks:

    • Execute programming tasks: If you need it to modify code, such as fixing a bug or adding a feature, enter clear instructions and then click the Code button. For example: “Please fix the separability_matrix calculation issue in the Modeling of the astropy/astropy library.”
    • Ask about the code repository: If you want to learn about certain aspects of the code repository, enter your question and click the Ask button. For example: “Please explain where the user authentication handling logic is.”

  3. Monitor and Wait:

    • Once the task begins, Codex will automatically work in the background sandbox environment; complex tasks may take 1 to 30 minutes.
    • Monitor the execution progress in real-time to understand the operations being performed, such as reading files, running commands, etc.

  4. Review Results:

    • After task completion, Codex will submit the code changes made in the sandbox environment.
    • It provides a detailed report including verifiable operational evidence, such as executed terminal command logs and test output results, facilitating user traceability of each step and ensuring transparency.
    • Users can carefully review the modified code, commit information, and test results.

  5. Subsequent Actions:

    • Request Modifications: If results do not meet expectations, further modification requests can be made.
    • Create a Change Request: If satisfied, you can let Codex create a GitHub pull request (PR) with one click for team code review.
    • Integrate Locally: Choose to integrate changes directly into the local development environment.

Guiding Codex with the AGENTS.md File

To make Codex more efficient and accurate in completing tasks, a AGENTS.md file can be created in the code repository, similar to a README.md manual.

  • Purpose: The file can indicate how Codex should navigate the codebase, which testing instructions to execute, the coding standards followed by the project, and the standard operating procedures.
  • Example content: 
    # AGENTS.md
## How to Run Tests
To run the full test suite, execute the following command in the project root directory:
`pytest`
## Coding Standards
This project follows PEP 8 coding standards. Please ensure there are no errors after running `flake8 .` before submitting code.
## Key Module Descriptions
- `src/core/auth.py`: User authentication and session management.
- `src/api/v1/`: All API endpoint definitions for version 1.

Just like a human developer, Codex performs better when the development environment is well-configured, the testing framework is stable, and the documentation is clear.

Application Scenarios

  1. Automating daily maintenance tasks: For repetitive and clearly defined tasks, such as code refactoring or adding unit tests, Codex can be delegated to handle these, allowing developers to focus on more creative work.
  2. Quickly fixing known bugs: When a clear error report is received, developers can directly hand it over to Codex, which will automatically fix the issue and validate.
  3. Building new feature frameworks: When developing new features, Codex can be tasked with establishing the basic framework, such as API endpoints.
  4. Enhancing codebase quality: Codex can be assigned to execute tasks aimed at improving code quality, such as formatting non-compliant code.

FAQ

  1. Is it safe to connect my private code repository to Codex?: Yes, Codex executes tasks in a completely isolated secure cloud sandbox container. It cannot access external websites or services during this time.
  2. Is the AGENTS.md file mandatory?: It is not mandatory, but it can significantly improve Codex’s performance by providing project guidelines to help it integrate faster.
  3. What is the difference between Codex and requesting code in ChatGPT?: The former operates in a real development environment, while the latter only generates code in text form, and the operating methods differ.
  4. What is the task execution time for Codex?: Generally, it takes 1 to 30 minutes, as it involves multiple steps, simulating the workflow of real developers.
