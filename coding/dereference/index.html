Dereference：A Development Tool for Running Multiple AI Models in Parallel

www.dereference.dev/

Dereference is an IDE tailored for developers, supporting the simultaneous management of various AI sessions with efficient functionalities.

Dereference is an integrated development environment (IDE) designed for developers, allowing them to operate in parallel across multiple AI sessions with large language models. The main feature of the tool is its support for simultaneous processing, enabling users to quickly switch between models such as Claude, GPT-4, and Gemini, while maintaining independent context for each conversation. It also adopts Git-like branching and merging mechanisms, allowing users to create branches from any point in a conversation to explore different solutions and later merge the best answers back. The tool is built using Rust, ensuring exceptional performance and paying special attention to privacy, with all conversation data and API keys stored locally and not uploaded to the server.

Features List

  • Parallel AI Sessions: Supports simultaneous conversations with multiple AI models (such as Claude, GPT-4, Gemini) and allows instant switching.
  • Branching and Merging: Similar to Git operations, users can create branches from any node to explore multiple solutions and then merge the desired results back into the main branch.
  • Multi-session Orchestration: Manage multiple AI sessions simultaneously, with each session maintaining independent context for comparing different model outputs.
  • Atomic Branching: Similar to code handling, conversations can be branched and merged without losing important context.
  • Native Application Performance: Built with Rust, it offers fast response times and low memory usage, avoiding performance loss encountered with frameworks like Electron.
  • Privacy First: Users’ conversation content and API keys are stored in the local keychain, ensuring they are not uploaded to the cloud.
  • Command Line Tool Integration: Currently natively supports integration with the Claude Code CLI tool, with plans to support more language model CLI tools in the future.
  • Intelligent Context Management: Automatically manages the context window for each session, with intelligent truncation techniques ensuring that important information is retained.

Usage Help

Dereference is a tool designed to enhance development efficiency, featuring a straightforward usage process. Users can directly download the applicable version from the official website, eliminating complex configurations.

Download and Launch

  1. Visit the official website https://www.dereference.dev/.
  2. Click the “Download” button on the page and select the version suitable for your operating system (such as macOS, Windows, or Linux).
  3. After downloading, unzip the file and run the application without installation; it works right out of the box.

Core Function Operations

1. Create and Manage Parallel AI Sessions Once the application is launched, users will see a clean interface.

  • Add New Session: Used to easily add new AI conversation tabs, allowing different sessions for different tasks. For example, one for code generation and another for code debugging.
  • Switch Models: In each session, users can conveniently select which AI model (like Claude, GPT-4, or Gemini) to use, quickly switching to leverage different model characteristics.

2. Use Branching and Merging Features This is one of the standout features of Dereference, inspired by the philosophy of Git version control.

  • Create Branch: If not completely satisfied with an answer, click “Create Branch” to start a new exploration at the conversation node.
  • Explore Different Solutions: The new branch inherits the previous conversation history and allows for free questioning without disrupting the original context, supporting parallel exploration of various solutions.
  • Merge Branch: Once a satisfactory result is found, the content of that branch can be merged back into the main conversation flow, suitable for tasks requiring iterative refinement.

3. Configure API Keys To use different AI models, the corresponding API keys need to be provided.

  • Local Storage: Dereference prioritizes user privacy by securely storing all API keys in the local device’s keychain.
  • Add Keys: In the settings menu, find the API key management option and enter the API keys for Claude, OpenAI, or Google Gemini.

4. Intelligent Context Management Dereference automatically manages the context for each session, ensuring that it does not exceed model limits while retaining important information. Utilizing intelligent truncation methods guarantees that key information is preserved, ensuring that the AI can understand the task background.

Application Scenarios

  1. Complex Code Logic Development: When implementing complex algorithms, questions can be posed simultaneously to GPT-4, Claude, and Gemini to find the best solution.
  2. Code Debugging and Error Fixing: Systematically exploring repair pathways without easily confusing contexts.
  3. Technical Research and Learning: Core concepts can be recorded, and branches can be created for in-depth exploration of knowledge points.
  4. Multi-language Project Development: Create independent AI sessions for different programming languages, facilitating efficient work in a multi-language environment.

QA

  3. Which AI models are supported? Currently supports Claude, Perplexity, Google Gemini, and OpenAI’s GPT models.
