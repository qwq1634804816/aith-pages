OpenCode：AI Programming Agent Running in Terminal Environment

github.com/sst/opencode

OpenCode is an open-source AI programming tool specifically designed for terminal environments, aimed at helping developers efficiently complete programming tasks.

OpenCode is an open-source AI programming agent built specifically for terminal environments. It enables developers to generate, modify, and debug code within the command line interface without leaving their current environment. Its main advantages are flexibility and openness. Users can choose to connect different AI models, such as Anthropic, OpenAI, and Google, or even local private models. This design avoids vendor lock-in while allowing users to benefit from price and performance competition among models.

OpenCode adopts a client/server architecture, allowing core services to run on a single machine while developers can connect remotely through other devices (such as laptops or smartphones). For developers using terminal tools like Neovim, OpenCode offers a seamless interactive experience that combines AI programming capabilities with a familiar work environment.

Feature List

  • Native Terminal Experience: Provides a complete terminal user interface (TUI) for smooth interaction with AI.
  • No Vendor Lock-in: Supports multiple large language models, including Anthropic (recommended), OpenAI, Google, and local models.
  • Open Source: The project is fully open source, licensed under MIT, making it easy for developers to review, modify, and distribute.
  • Client/Server Architecture: Allows remote connection and operation of AI agent services.
  • Cross-Platform Installation: Supports mainstream operating systems like macOS and Linux and adapts to various package managers.
  • Community Driven: The project is community-supported, encouraging code contributions, bug fixes, and documentation improvements.

Usage Help

OpenCode is dedicated to simplifying the installation and usage processes for developers, facilitating quick onboarding.

Installation Process

OpenCode offers multiple installation methods to accommodate different operating systems and user preferences. You can choose the method that suits you best.

1. Quick Install (Recommended)

For most macOS and Linux users, using the official one-click installation script is the easiest option. Open the terminal and run:

curl -fsSL https://opencode.ai/install | bash

This script will automatically detect your system environment and install OpenCode in the appropriate location.

2. Using Package Manager to Install

If you prefer to use a package manager, you can also install OpenCode through them.

  • For npm / bun / pnpm / yarn users:
npm i -g opencode-ai@latest
  • For Homebrew users on macOS and Linux: After adding the software source, use:
brew install sst/tap/opencode
  • For Arch Linux users: Use paru or another AUR helper:
paru -S opencode-bin

Important Note

Before installing a new version, please ensure to uninstall all older versions below 0.1.x to avoid conflicts.

Custom Installation Directory

By default, the installation script determines the installation directory in the following priority:

  1. $OPENCODE_INSTALL_DIR: If this environment variable is set, it will serve as the preferred installation path.
  2. $XDG_BIN_DIR: Follows the XDG base directory specification.
  3. $HOME/bin: The default personal binary directory.
  4. $HOME/.opencode/bin: Alternate installation path.

If you wish to install OpenCode to a specific location, such as /usr/local/bin, you can set the environment variable before executing the installation script:

OPENCODE_INSTALL_DIR=/usr/local/bin curl -fsSL https://opencode.ai/install | bash

Basic Usage

Once installed, you can start the user interface (TUI) by directly entering the opencode command in the terminal.

  1. Start OpenCode: Type opencode to launch.
  2. Interact with AI: In the interactive environment, you can input requests like a chat tool, for example:
    • “Please help me write a Python function to calculate the Fibonacci sequence.”
    • “Analyze the performance bottlenecks of this code and provide optimization suggestions.”
    • “Convert this JSON file to CSV format.”
  3. Code Operations: After the AI generates code, you can copy, modify, or save it. OpenCode’s TUI design references terminal editors like Neovim, making the operations very efficient.

Configuration Instructions

The design of OpenCode does not rely on a single AI model vendor. Users need to specify the desired model in the configuration file, which can be referenced in the official documentation. Typically, it is necessary to provide the API key of the selected AI service provider and configure it. This allows for flexible switching and ensures the selection of the most cost-effective model.

For more detailed configuration and advanced usage, such as local model setup or remote connections, please visit the official documentation.

Application Scenarios

  1. Rapid Development and Prototyping in the Terminal: Developers can start OpenCode directly in the terminal and describe requirements in natural language to achieve efficient development.
  2. Remote Server Programming and Maintenance: OpenCode, as a terminal tool, can run on remote servers, supporting various programming and maintenance tasks.
  3. Learning New Technologies and APIs: Users can directly ask questions to obtain code samples, accelerating the learning process.
  4. Automated Script Writing: OpenCode is an excellent assistant for system administrators and DevOps engineers, capable of quickly generating various script codes.
